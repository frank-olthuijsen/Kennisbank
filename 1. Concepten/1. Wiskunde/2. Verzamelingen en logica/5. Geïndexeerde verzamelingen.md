- Verzamelingen $A,B,C$ kunnen geschreven worden als geïndexeerde verzamelingen $A_1,A_2,A_3$
- Als $A_1,A_2,\text{...},A_n$ verzamelingen zijn. Dan
	- $A_1 \cup A_2 \cup A_3 \cup \text{...} \cup A_n=\{x|x \in A_i \text{ voor tenminste een set } A_i, \text{ voor } 1 \leq i \leq n \}$
	- $A_1 \cap A_2 \cap A_3 \cap \text{...} \cap A_n=\{x|x \in A_i \text{ voor iedere set } A_i, \text{ voor } 1 \leq i \leq n \}$
- Hoofdstuk eventueel verder samenvatten.
