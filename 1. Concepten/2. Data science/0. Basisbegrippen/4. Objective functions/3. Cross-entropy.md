## Cross-entropy

> [!info] Cross-entropy
> **Cross-entropy** meet hoe goed een voorspelde kansverdeling $q$ overeenkomt met de werkelijke kansverdeling $p$. Hoe meer kans $q$ toekent aan uitkomsten die volgens $p$ waarschijnlijk zijn, hoe lager de cross-entropy.
>
> Voor discrete uitkomsten geldt:
>
> $H(p,q)=-\sum_{i\in D}p_i\log q_i$
>
> waarbij:
> - $p_i$ = werkelijke kans op uitkomst $i$;
> - $q_i$ = voorspelde kans op uitkomst $i$;
> - $D$ = verzameling mogelijke uitkomsten.
>
> Voor continue verdelingen geldt:
>
> $H(p,q)=-\int_D p(x)\log q(x)\,dx$
>
> In machine learning wordt cross-entropy veel gebruikt als [[2. Loss function|loss function]] bij classification. Bij een one-hot target blijft alleen de voorspelde kans van de werkelijke class over: hoe hoger die kans, hoe lager de loss.
>
> Meestal wordt voor $\log$ de natuurlijke logaritme gebruikt.

> [!example]+ Voorbeeld
> Een classifier voorspelt voor drie classes:
>
> $q=(0{,}1,\ 0{,}7,\ 0{,}2)$
>
> De tweede class is werkelijk correct, dus:
>
> $p=(0,\ 1,\ 0)$
>
> De cross-entropy is:
>
> $H(p,q)=-(0\log0{,}1+1\log0{,}7+0\log0{,}2)=-\log0{,}7\approx0{,}357$
>
> Als het model slechts $0{,}1$ kans aan de juiste class had toegekend, zou de cross-entropy $-\log0{,}1\approx2{,}303$ zijn. Een slechtere voorspelling geeft dus een hogere loss.
