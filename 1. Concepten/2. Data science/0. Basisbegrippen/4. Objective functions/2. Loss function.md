## Loss function

> [!info] Loss function
> Een **loss function** is een functie die uitdrukt **hoe slecht** de voorspellingen van een model overeenkomen met de gewenste uitkomsten.
> 
> Een hogere loss betekent een grotere fout. Tijdens training probeert het *training algorithm* daarom waarden voor de modelparameters te vinden waarmee de loss wordt **geminimaliseerd**.
> 
> **Loss function** en **cost function** worden vaak als synoniemen gebruikt. Soms wordt met _loss_ de fout van één waarneming bedoeld en met _cost_ de gecombineerde fout over meerdere waarnemingen.
> 
> Engels ook; **cost function**

> [!example]+ Voorbeeld  
> Bij **linear regression** kan de [[1. Regression metrics#Mean Squared Error (MSE)|mean squared error (MSE]] als loss function worden gebruikt.
> 
> Het training algorithm zoekt dan parameterwaarden waarvoor het verschil tussen de voorspelde en werkelijke waarden zo klein mogelijk is.
## Relatie met performance metrics

Een functie die errors van een model meet, kan afhankelijk van het gebruik verschillende rollen hebben:

- Als de functie tijdens [[1. Training|training]] wordt geminimaliseerd om de model parameters te leren, wordt deze gebruikt als **loss function** of **cost function**.
- Als dezelfde functie wordt gebruikt om de performance van een model te beoordelen, wordt deze gebruikt als [[1. Performance metric#Performance metric|performance metric]].

Dezelfde wiskundige functie kan dus zowel een cost function als een performance metric zijn. De termen beschrijven in dat geval niet een andere formule, maar een andere **rol** van die formule.

> [!example]+ Voorbeeld
> [[1. Regression metrics#Mean Absolute Error (MAE)|MAE (Mean Absolute Error)]] kan tijdens training worden geminimaliseerd en fungeert dan als cost function.
>
> Dezelfde MAE kan na training op validation data of test data worden berekend om de performance van het model te beoordelen. MAE fungeert dan als performance metric.
>
> Hetzelfde principe geldt voor RMSE, hoewel bij training vaak MSE wordt geminimaliseerd in plaats van RMSE.
