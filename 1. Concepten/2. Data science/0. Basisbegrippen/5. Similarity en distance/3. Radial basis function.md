## Radial basis function (RBF)

> [!info] Radial basis function (RBF)
> Een **radial basis function (RBF)** is een functie waarvan de waarde uitsluitend afhangt van de [[2. Distance function#Distance function|distance]] tussen een datapunt en een centraal punt.
>
> Bij veelgebruikte RBF's krijgen punten dicht bij het centrum een hoge waarde en punten verder weg een lagere waarde.
>
> RBF's worden onder andere gebruikt voor:
> - **Similarity:** de overeenkomst tussen een datapunt en een referentiepunt uitdrukken als een numerieke score.
> - **Feature engineering:** nieuwe [[2. Feature, label en target#Feature|features]] creëren die aangeven hoe dicht een waarde bij een bepaald referentiepunt ligt. Dit kan bijvoorbeeld nuttig zijn bij een [[2. Multimodale verdeling#Multimodale verdeling (multimodal distribution)|multimodal distribution]], waarbij meerdere centra worden gekozen.
> - **Kernel methods:** niet-lineaire relaties modelleren, bijvoorbeeld door een RBF als [[2. Kernel#Kernel|kernel]] te gebruiken in een [[1. Support vector machine (SVM)|support vector machine (SVM)]].
> - **Radial basis function networks:** RBF's gebruiken als activatiefuncties in een neural network.
>
> Een veelgebruikte variant is de [[4. Gaussian RBF#Gaussian RBF|Gaussian RBF]].

> [!example]+ Voorbeeld
> Stel dat een dataset de reistijd naar het werk bevat, met twee duidelijke toppen rond $15$ en $50$ minuten.
>
> Met RBF's kunnen twee nieuwe features worden gecreëerd:
> - Een feature die aangeeft hoe dicht een reistijd bij $15$ minuten ligt.
> - Een feature die aangeeft hoe dicht een reistijd bij $50$ minuten ligt.
>
> Een reistijd van $17$ minuten krijgt een hoge score voor het eerste centrum en een lage score voor het tweede centrum.
>
> Zo kan een model de nabijheid tot beide toppen afzonderlijk gebruiken om niet-lineaire relaties te leren.
