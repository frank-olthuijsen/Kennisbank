## Cost function versus performance metric

Een functie die errors van een model meet, kan afhankelijk van het gebruik verschillende rollen hebben:

- Als de functie tijdens [[1. Training|training]] wordt geminimaliseerd om de model parameters te leren, wordt deze gebruikt als [[2. Cost function#Cost function|cost function]].
- Als dezelfde functie wordt gebruikt om de performance van een model te beoordelen, wordt deze gebruikt als [[Kennisbank/1. Concepten/2. Data science/0. Basisbegrippen/6. Evaluation/1. Performance metric#Performance metric|performance metric]].

Dezelfde wiskundige functie kan dus zowel een cost function als een performance metric zijn. De termen beschrijven in dat geval niet een andere formule, maar een andere **rol** van die formule.

> [!example]+ Voorbeeld
> [[4. MAE#Mean Absolute Error (MAE)|MAE (Mean Absolute Error)]] kan tijdens training worden geminimaliseerd en fungeert dan als cost function.
>
> Dezelfde MAE kan na training op validation data of test data worden berekend om de performance van het model te beoordelen. MAE fungeert dan als performance metric.
>
> Hetzelfde principe geldt voor RMSE, hoewel bij training vaak MSE wordt geminimaliseerd in plaats van RMSE.
