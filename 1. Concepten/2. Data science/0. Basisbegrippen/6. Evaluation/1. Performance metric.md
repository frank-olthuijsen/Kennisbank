## Performance metric

> [!info] Performance metric  
> Een **performance metric** is een kwantitatieve maat waarmee wordt beoordeeld hoe goed een [[1. Model#Model|model]] presteert op een bepaalde taak.
> 
> Een performance metric wordt doorgaans berekend op _validation data_ of _test data_. Afhankelijk van de metric betekent een hogere of juist een lagere waarde betere performance.
> 
> Welke performance metric geschikt is, hangt af van de taak en van welk aspect van de modelperformance belangrijk is.
> 
> Engels ook: **performance measure**
> 
> Zie ook [[3. Cost function versus performance metric#Cost function versus performance metric|cost function versus performance metric]].

> [!example]+ Voorbeeld  
> Bij _classification_ kunnen bijvoorbeeld [[2. Accuracy#Accuracy|accuracy]], [[3. Precision, recall en specificity#Precision|precision]] en [[3. Precision, recall en specificity#Recall|recall]] als performance metric worden gebruikt.
> 
> Bij _regression_ kunnen bijvoorbeeld [[2. RMSE#Root Mean Squared Error (RMSE)|RMSE]] en [[4. MAE#Mean Absolute Error (MAE)|MAE]] worden gebruikt.
> 
> De keuze voor een performance metric bepaalt welk aspect van de prestaties van het model wordt beoordeeld. Een model met een hoge _accuracy_ hoeft bijvoorbeeld niet automatisch een hoge _recall_ te hebben.
