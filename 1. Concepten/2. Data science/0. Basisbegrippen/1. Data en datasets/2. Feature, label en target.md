## Feature

> [!info] Feature  
> Een **feature** is een meetbare eigenschap of invoervariabele die een [[1. Dataset en observation#Waarneming (observation)|waarneming]] beschrijft en als input kan worden gebruikt voor een analyse of model.
> 
> Een waarneming bevat doorgaans meerdere features.
> 
> Engels ook: **input variable**, **predictor**, **attribute**

> [!example]+ Voorbeeld  
> In een dataset met patiëntgegevens kunnen de volgende eigenschappen features zijn:
> 
> - leeftijd
>     
> - bloeddruk
>     
> - BMI
>     
> - cholesterolwaarde
>     
> 
> Iedere patiënt is één waarneming en deze waarden beschrijven eigenschappen van die patiënt.
## Feature space

> [!info] Feature space  
> De **feature space** is de ruimte van alle mogelijke combinaties van waarden van de [[2. Feature, label en target#Feature|features]] waarmee _observations_ worden beschreven.
> 
> Iedere _feature_ vormt een dimensie van de _feature space_. Een _observation_ kan daardoor als een punt in deze ruimte worden weergegeven.

> [!example]+ Voorbeeld  
> Een dataset bevat twee _features_: `leeftijd` en `bloeddruk`. De _feature space_ is dan tweedimensionaal:
> 
> - de ene as stelt `leeftijd` voor;
>     
> - de andere as stelt `bloeddruk` voor.
>     
> 
> Een patiënt van 65 jaar met een bloeddruk van 140 kan daarin worden weergegeven als het punt $(65,140)$.
## Target

> [!info] Target  
> De **target** is bij [[1. Supervised learning|supervised learning]] de bekende uitkomst die een model op basis van de [[2. Feature, label en target#Feature|features]] probeert te leren voorspellen.
> 
> De target kan bijvoorbeeld een categorie zijn bij [[1. Classification|classification]] of een numerieke waarde bij [[1. Regression|regression]].

> [!example]+ Voorbeeld  
> Een model probeert de opnameduur van een patiënt te voorspellen.
> 
> - **Features** zijn bijvoorbeeld leeftijd, diagnose en eerdere opnames.
>     
> - De **target** is het aantal dagen dat de patiënt opgenomen blijft.
>     
## Y-hat

> [!info] Y-hat
> **Y-hat**, geschreven als $\hat{y}$, is de door een model **voorspelde waarde van de [[2. Feature, label en target#Target|target]]**.
>
> Voor één [[1. Dataset en observation#Observation|observation]] wordt de voorspelling vaak geschreven als:
>
> $\hat{y}^{(i)}=h(x^{(i)})$
>
> Hierbij is:
> - $x^{(i)}$ de feature vector van observation $i$
> - $h$ het model
> - $\hat{y}^{(i)}$ de voorspelde target value voor observation $i$
>
> De werkelijke target value wordt geschreven als $y^{(i)}$. Het verschil tussen $\hat{y}^{(i)}$ en $y^{(i)}$ vormt de [[1. Prediction error#Prediction error|prediction error]].
>
> Wanneer $\hat{y}$ zonder index wordt gebruikt, kan het ook de vector met voorspelde target values voor alle observations aanduiden.

> [!example]+ Voorbeeld
> Een regression model voorspelt de opnameduur van een patiënt.
>
> Voor één patiënt geldt bijvoorbeeld:
>
> $y^{(i)}=5$
>
> $\hat{y}^{(i)}=7$
>
> De werkelijke opnameduur is dus $5$ dagen en het model voorspelt $7$ dagen.
## Label

> [!info] Label  
> Een **label** is de bekende target bij een [[1. Classification|classification]]-taak en geeft aan tot welke class een waarneming behoort.
> 
> `Label` wordt dus vooral gebruikt wanneer de te voorspellen uitkomst een categorie is.

> [!example]+ Voorbeeld  
> Een model moet bepalen of een huidafwijking goedaardig of kwaadaardig is.
> 
> - **Features** zijn bijvoorbeeld grootte, vorm en kleur.
>     
> - Het **label** is `goedaardig` of `kwaadaardig`.
>     
## Ground truth

> [!info] Ground truth  
> **Ground truth** is de waarde of het [[2. Feature, label en target#Label|label]] die binnen een dataset als de **juiste referentie** wordt beschouwd en waarmee bijvoorbeeld de voorspelling van een model wordt vergeleken.
> 
> Ground truth hoeft niet letterlijk de absolute waarheid te zijn. Het kan bijvoorbeeld afkomstig zijn van een meting, observatie of beoordeling door een expert en kan daardoor zelf onzekerheden of fouten bevatten.

> [!example]+ Voorbeeld  
> Een model voorspelt op basis van een röntgenfoto of een patiënt een longontsteking heeft.
> 
> - De voorspelling van het model is `longontsteking`.
>     
> - De diagnose die door een radioloog als referentie is vastgesteld, is `geen longontsteking`.
>     
> 
> De diagnose `geen longontsteking` vormt in deze dataset de **ground truth** waarmee de voorspelling van het model wordt vergeleken.
## Relatie

Bij supervised learning vormen de begrippen samen grofweg:

```text
features → model → target
```

Bij classification wordt de target meestal een **label** genoemd:

```text
features → classification model → label
```

Bij regression wordt doorgaans de algemenere term **target** gebruikt:

```text
features → regression model → numerieke target
```

## Verklarende variabele

> [!info] Verklarende variabele  
> Een **verklarende variabele** is een variabele die in een model wordt gebruikt om verschillen of veranderingen in een [[2. Feature, label en target#Target|target]] te verklaren of te voorspellen.
> 
> In een eenvoudig linear regression model:
> 
> $\hat y=\theta_0+\theta_1x$
> 
> is $x$ de verklarende variabele en $\hat y$ de voorspelde target value.
> 
> Wanneer het theoretische verband inclusief de [[8. Error term#Error term|error term]] wordt beschreven:
> 
> $Y=\theta_0+\theta_1X+\varepsilon$
> 
> is $X$ de verklarende variabele en $Y$ de variabele die wordt verklaard.
> 
> Binnen machine learning komt een verklarende variabele doorgaans overeen met een [[2. Feature, label en target#Feature|feature]] die als input aan het model wordt aangeboden.
> 
> De term **verklarend** betekent niet automatisch dat $X$ een causale invloed op $Y$ heeft. Het model kan ook alleen een statistisch verband tussen beide variabelen beschrijven.
> 
> Engels: **explanatory variable**, ook vaak **predictor** of **independent variable**.

> [!example]+ Voorbeeld  
> Een linear regression model voorspelt de bloeddruk op basis van leeftijd:
> 
> $\hat y=\theta_0+\theta_1x$
> 
> waarbij $x$ de leeftijd voorstelt.
> 
> `leeftijd` is hier de **verklarende variabele** en `bloeddruk` de target.
> 
> Dat het model een verband tussen leeftijd en bloeddruk vindt, betekent op zichzelf nog niet dat een causaal verband is aangetoond.
