## Bootstrap sample

> [!info] Bootstrap sample  
> Een **bootstrap sample** is een nieuwe sample die wordt gemaakt door willekeurig [[1. Dataset en observation#Observation|observations]] uit een bestaande dataset te trekken **met teruglegging**.
> 
> Doordat met teruglegging wordt getrokken, kan dezelfde observation meerdere keren in de bootstrap sample voorkomen, terwijl andere observations helemaal niet worden geselecteerd.
> 
> Een bootstrap sample heeft doorgaans dezelfde grootte als de oorspronkelijke dataset.
> 
> Bootstrap samples worden onder andere gebruikt bij [[4. Bagging#Bagging|bagging]], waarbij verschillende modellen op verschillende bootstrap samples worden getraind.

> [!example]+ Voorbeeld  
> Een dataset bestaat uit vijf observations:
> 
> `A, B, C, D, E`
> 
> Een mogelijke bootstrap sample van dezelfde grootte is:
> 
> `B, D, B, A, D`
> 
> `B` en `D` komen meerdere keren voor, terwijl `C` en `E` niet zijn geselecteerd.
