- **Machine learning (ML**) is the science of programming computers so they can **learn from data**.
- ML is very well suited for:
	- Problems for which existing solutions require a lot of work and maintenance.
		- E.g., long lists of rules for classifying spam/ham.
	- Complex problems for which using a traditional approach yield no good solutions.
		- E.g., speech recognition.
	- Fluctuating environments.
		- E.g. retraining a spam filter on new data.
	- Getting insights about complex problems and large amounts of data.
		- E.g. data mining.
