## Hypothesis function

> [!info] Hypothesis function  
> Een **hypothesis function** is de wiskundige functie die een machine-learningmodel gebruikt om op basis van een [[2. Feature, label en target#Feature|feature vector]] een _prediction_ te berekenen.
> 
> De functie wordt doorgaans genoteerd als:
> 
> $h_{\vec{\theta}}(\vec{x})$
> 
> Hierbij geldt:
> 
> - $\vec{x}$ is de _feature vector_ met de invoerwaarden.
>     
> - $\vec{\theta}$ is de vector met de _model parameters_.
>     
> - $h_{\vec{\theta}}(\vec{x})$ is de output van het model.
>     
> 
> De vorm van de functie hangt af van het gekozen model. Tijdens training worden de _model parameters_ aangepast om de _predictions_ zo goed mogelijk te laten aansluiten bij de bekende _target values_.
> 
> Bij [[2. Linear regression#Linear regression|linear regression]] is de hypothesis function een lineaire combinatie van de features:
> 
> $h_{\vec{\theta}}(\vec{x})=\vec{\theta}^{\mathrm{T}}\vec{x}$
> 
> Hierbij bevat $\vec{x}$ ook de constante feature $x_0=1$, zodat het _intercept_ wordt meegenomen.
> 
> De term _hypothesis_ verwijst hier naar de door het model gekozen voorspellingsfunctie, niet naar een statistische hypothese.
