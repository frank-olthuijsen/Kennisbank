## Softmax function

> [!info] Softmax function  
> De **softmax function** zet een vector $\mathbf{s}(\mathbf{x})$ met scores voor $K$ classes om in een vector van waarden tussen $0$ en $1$ die samen optellen tot $1$.
> 
> Voor class $k$ wordt de [[3. Estimated probability#Estimated probability|estimated probability]] berekend als:
> 
> $\hat{p}_k=\sigma(\mathbf{s}(\mathbf{x}))_k=\frac{\exp(s_k(\mathbf{x}))}{\sum_{j=1}^{K}\exp(s_j(\mathbf{x}))}$
> 
> Hierbij is
> - $\sigma$  de softmax function
> -  $\mathbf{s}(\mathbf{x})$ de vector met scores voor alle classes van observation $\mathbf{x}$;
> - $s_k(\mathbf{x})$ de score voor class $k$;
> - $K$ het totale aantal classes.
> 
> De volledige output $\sigma(\mathbf{s}(\mathbf{x}))$ vormt een probability distribution over de classes.
