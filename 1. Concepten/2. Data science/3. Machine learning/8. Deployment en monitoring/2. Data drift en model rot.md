> [!info] Data drift  
> **Data drift** is het verschijnsel waarbij de eigenschappen of verdeling van de data die een model in productie ontvangt na verloop van tijd veranderen ten opzichte van de data waarop het model is getraind.
> 
> Hierdoor sluit de trainingsdata steeds minder goed aan op de actuele situatie. Data drift kan daardoor leiden tot slechtere voorspellingen.

> [!info] Model rot  
> **Model rot** is het geleidelijk verslechteren van de prestaties van een machine-learningmodel doordat de omstandigheden waarin het model wordt gebruikt veranderen.
> 
> **Data drift** kan een oorzaak zijn van model rot, maar model rot kan ook andere oorzaken hebben.

> [!example]+ Voorbeeld  
> Een ziekenhuis traint een model om op basis van laboratoriumwaarden een risico te voorspellen.
> 
> Na verloop van tijd wordt nieuwe meetapparatuur ingevoerd, waardoor bepaalde laboratoriumwaarden systematisch anders worden gemeten. De verdeling van de inputdata verandert ten opzichte van de trainingsdata: er is sprake van **data drift**.
> 
> Als het model hierdoor steeds minder nauwkeurige voorspellingen doet, is er sprake van **model rot**.
