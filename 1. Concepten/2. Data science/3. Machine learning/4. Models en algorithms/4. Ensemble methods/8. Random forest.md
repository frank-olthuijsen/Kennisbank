## Random forest

> [!info] Random forest  
> Een **random forest** is een [[4. Bagging#Bagging|bagging]]-ensemble van [[1. Decision tree#Decision tree|decision trees]] dat kan worden gebruikt voor zowel [[1. Classification#Classification|classification]] als [[1. Regression#Regression|regression]].
>  
> Naast de randomisatie die door bagging ontstaat, wordt bij iedere splitsing in een decision tree slechts een willekeurige subset van de beschikbare _features_ overwogen.
> 
> Deze extra randomisatie vergroot de diversiteit tussen de decision trees en kan daarmee de generalisatie van het ensemble verbeteren.
> 
> De _predictions_ van de afzonderlijke _decision trees_ worden vervolgens gecombineerd:
> 
> - bij _classification_ bijvoorbeeld via meerderheidsstemming;     
> - bij _regression_ bijvoorbeeld door de voorspelde waarden te middelen.

> [!example]+ Voorbeeld  
> Een random forest wordt gebruikt om huidafwijkingen te classificeren als `goedaardig` of `kwaadaardig` en bestaat uit $100$ _decision trees_.
> 
> Als $78$ _decision trees_ `kwaadaardig` voorspellen en $22$ _decision trees_ `goedaardig`, kan het random forest via meerderheidsstemming de uiteindelijke _class_ `kwaadaardig` voorspellen.
> 
> Bij een _regression task_ zouden de _decision trees_ in plaats daarvan numerieke waarden voorspellen. Het random forest kan deze waarden vervolgens combineren, bijvoorbeeld door het gemiddelde te nemen.
## Verschil met random subspaces

Bij [[7. Random subspaces#Random subspaces|random subspaces]] krijgt ieder model een willekeurige subset van de beschikbare _features_. Het model wordt vervolgens uitsluitend met die subset getraind.

Bij een **random forest** krijgt een [[1. Decision tree#Decision tree|decision tree]] daarentegen niet één vaste subset van features voor de hele tree. Bij **iedere afzonderlijke split** wordt opnieuw een willekeurige subset van de beschikbare features geselecteerd, waarna uit die subset de beste split wordt gekozen.

Conceptueel:

```
Random subspaces:
model 1 → features {A, C, D}
model 2 → features {B, D, E}
model 3 → features {A, B, E}

Random forest:
tree 1
├── split 1 → willekeurige feature-subset
├── split 2 → nieuwe willekeurige feature-subset
└── split 3 → opnieuw een nieuwe willekeurige feature-subset
```

Een random forest combineert deze feature-randomisatie met [[4. Bagging#Bagging|bagging]] van decision trees.
