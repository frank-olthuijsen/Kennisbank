## Softmax regression

> [!info] Softmax regression  
> **Softmax regression** is een uitbreiding van [[1. Logistic regression#Logistic regression|logistic regression]] voor [[2. Multiclass classification#Multiclass classification|multiclass classification]], waarbij een model één van meerdere mogelijke classes voorspelt.
> 
> Het model berekent voor iedere class $k$ een score op basis van een lineaire combinatie van de features:
> 
> $z_k=b_k+w_{k1}x_1+w_{k2}x_2+\dots+w_{kn}x_n$
> 
> Vervolgens zet de **softmax function** deze scores om in [[3. Estimated probability#Estimated probability|estimated probabilities]]:
> 
> $p_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}$
> 
> Hierbij geldt:
> 
> - $z_k$ is de score voor class $k$.
>     
> - $K$ is het totale aantal classes.
>     
> - $p_k$ is de _estimated probability_ voor class $k$.
>     
> 
> De _estimated probabilities_ liggen tussen $0$ en $1$ en tellen samen op tot $1$.
> 
> De voorspelde class is de class met de hoogste _estimated probability_.
> 
> Ook: **multinomial logistic regression**

> [!example]+ Voorbeeld  
> Een model classificeert afbeeldingen in drie classes: A, B en C.
> 
> Voor een afbeelding berekent het model de volgende scores:
> 
> - Class A: $z_A=1$
>     
> - Class B: $z_B=2$
>     
> - Class C: $z_C=0$
>     
> 
> De softmax function berekent voor class B:
> 
> $p_B=\frac{e^2}{e^1+e^2+e^0}\approx0{,}665$
> 
> De _estimated probabilities_ voor alle classes zijn:
> 
> - Class A: $p_A\approx0{,}245$
>     
> - Class B: $p_B\approx0{,}665$
>     
> - Class C: $p_C\approx0{,}090$
>     
> 
> Samen zijn deze ongeveer $1$.
> 
> Omdat class B de hoogste _estimated probability_ heeft, voorspelt het model **class B**.
