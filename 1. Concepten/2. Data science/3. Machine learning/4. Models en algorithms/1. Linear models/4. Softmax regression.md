## Softmax regression

> [!info] Softmax regression  
> **Softmax regression** is een uitbreiding van [[1. Logistic regression#Logistic regression|logistic regression]] voor [[2. Multiclass classification#Multiclass classification|multiclass classification]], waarbij voor iedere class $k$ een afzonderlijke score wordt berekend:
> 
> $s_k(\mathbf{x})=(\boldsymbol{\theta}^{(k)})^{\mathrm T}\mathbf{x}$
> 
> Hierbij is $\boldsymbol{\theta}^{(k)}$ de parameter vector voor class $k$ en $\mathbf{x}$ de feature vector van een observation.
> 
> De scores van alle classes vormen samen de vector $\mathbf{s}(\mathbf{x})$. De [[4. Softmax function#Softmax function|softmax function]] zet deze scorevector om in [[3. Estimated probability#Estimated probability|estimated probabilities]] voor de verschillende classes.
> 
> De voorspelde class $\hat{y}$ is de class met de hoogste _estimated probability_. Omdat de softmax function de volgorde van de scores behoudt, is dit ook de class met de hoogste score:
> 
> $\hat{y}=\underset{k}{\arg\max}\ \sigma(\mathbf{s}(\mathbf{x}))_k=\underset{k}{\arg\max}\ s_k(\mathbf{x})=\underset{k}{\arg\max}\left((\boldsymbol{\theta}^{(k)})^{\mathrm T}\mathbf{x}\right)$
> 
> Engels ook: **multinomial logistic regression**

> [!example]+ Voorbeeld  
> Een model classificeert afbeeldingen in drie classes: A, B en C.
> 
> Voor een afbeelding berekent het model de volgende scores:
> 
> - Class A: $z_A=1$
>     
> - Class B: $z_B=2$
>     
> - Class C: $z_C=0$
>     
> 
> De softmax function berekent voor class B:
> 
> $p_B=\frac{e^2}{e^1+e^2+e^0}\approx0{,}665$
> 
> De _estimated probabilities_ voor alle classes zijn:
> 
> - Class A: $p_A\approx0{,}245$
>     
> - Class B: $p_B\approx0{,}665$
>     
> - Class C: $p_C\approx0{,}090$
>     
> 
> Samen zijn deze ongeveer $1$.
> 
> Omdat class B de hoogste _estimated probability_ heeft, voorspelt het model **class B**.
