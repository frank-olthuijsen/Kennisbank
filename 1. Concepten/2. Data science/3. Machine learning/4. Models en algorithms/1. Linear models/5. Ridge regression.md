## Ridge regression

> [!info] Ridge regression  
> **Ridge regression** is een vorm van [[2. Linear regression#Linear regression|linear regression]] waarbij [[4. Regularization#Regularization|regularization]] wordt toegepast door grote waarden van de [[7. Model coefficients#Model coefficients|model coefficients]] te bestraffen.
> 
> Tijdens training wordt naast de [[1. Prediction error#Prediction error|prediction error]] een **L2-penalty** meegenomen:
> 
> $\text{loss}=\text{prediction error}+\frac{\alpha}{m}\sum_{i=1}^{n}\theta_i^2$
> 
> N.B. $i$ start bij $1$ omdat de bias term niet wordt gereguleerd.
> 
> Hierbij bepaalt de hyperparameter $\alpha$ de sterkte van de regularization en is $m$ het aantal training observations. Hoe groter $\alpha$, hoe sterker grote _model coefficients_ worden bestraft en richting $0$ worden gedrukt. Des te dichter $\alpha$ bij $0$ komt, des te meer het model zich gedraagt als ongereguleerde linear regression.
> 
> Ridge regression maakt het model daardoor minder gevoelig voor de specifieke training data en kan [[1. Overfitting en underfitting#Overfitting|overfitting]] verminderen. De coefficients worden doorgaans kleiner, maar niet exact $0$. 
> 
> Ridge regression is gevoelig voor de schaal van de data. Deze dient dan ook te worden [[4. Feature scaling#Feature scaling|geschaald]].
>
> De regularization term moet alleen worden toegevoegd aan de cost function tijdens training, niet om de model performance te bepalen.
>
>Een gebruikelijke vorm van de Ridge regression cost function is:
> 
> $J(\boldsymbol{\theta})=\operatorname{MSE}(\boldsymbol{\theta})+\frac{\alpha}{m}\sum_{i=1}^{n}\theta_i^2$
> 
> Hierbij geldt:
> 
> - $\operatorname{MSE}(\boldsymbol{\theta})$ meet hoe goed het model de training data fit;     
> - $\sum_{i=1}^{n}\theta_i^2$ is de **L2-penalty**;     
> - $\alpha$ bepaalt de sterkte van de regularization;     
> - $m$ is het aantal training observations;     
> - $\theta_1,\dots,\theta_n$ zijn de _model coefficients_.     
> 
> Het _intercept_ $\theta_0$ wordt normaal gesproken niet meegenomen in de regularization.
> 
> Ridge regression is een specifieke vorm van **Tikhonov regularization**.

> [!example]+ Voorbeeld  
> Stel dat een Ridge regression model twee _model coefficients_ heeft:
> 
> $\theta_1=2,\qquad\theta_2=-1$
> 
> Er zijn $m=4$ training observations, $\alpha=1$ en het model heeft:
> 
> $\operatorname{MSE}(\boldsymbol{\theta})=3$
> 
> De cost function is:
> 
> $J(\boldsymbol{\theta})=\operatorname{MSE}(\boldsymbol{\theta})+\frac{\alpha}{m}\sum_{i=1}^{n}\theta_i^2$
> 
> De L2-penalty is:
> 
> $\frac{1}{4}(2^2+(-1)^2)=\frac{5}{4}=1{,}25$
> 
> De totale cost wordt daardoor:
> 
> $J(\boldsymbol{\theta})=3+1{,}25=4{,}25$
> 
> Zonder regularization zou de cost alleen de MSE van $3$ zijn. Door Ridge regression komt daar een penalty van $1{,}25$ bij voor de grootte van de model coefficients.
> 
> Tijdens training probeert het model daarom niet alleen de prediction error te verkleinen, maar ook grote model coefficients te vermijden.
## Training

Ridge regression kan op verschillende manieren worden getraind. Het doel is steeds om de model coefficients te vinden waarvoor de Ridge regression cost function minimaal is.
### Closed-form solution

Omdat Ridge regression een lineair model is, kunnen de optimale model coefficients rechtstreeks worden berekend met een [[10. Oplossing in gesloten vorm#Oplossing in gesloten vorm|oplossing in gesloten vorm]]:

$\hat{\boldsymbol{\theta}}=(\mathbf{X}^{\mathrm{T}}\mathbf{X}+\alpha\mathbf{A})^{-1}\mathbf{X}^{\mathrm{T}}\mathbf{y}$

Hierbij is $\mathbf{A}$ een matrix die ervoor zorgt dat de _model coefficients_ worden geregulariseerd, maar het _intercept_ $\theta_0$ niet. Het is een $(n+1)\times(n+1)$ [[2. Bijzondere matrices#Identiteitsmatrix|identiteitsmatrix]] met een $0$ in het element linksboven.

Met deze methode worden de optimale parameters rechtstreeks berekend; er zijn geen iteratieve parameterupdates nodig.
### Gradient descent

Ridge regression kan ook worden getraind met [[1. Gradient descent#Gradient descent|gradient descent]].

Daarbij worden de model coefficients iteratief aangepast om de Ridge regression cost function te minimaliseren. De gradient bevat daarbij niet alleen het effect van de prediction error, maar ook van de L2-penalty.
