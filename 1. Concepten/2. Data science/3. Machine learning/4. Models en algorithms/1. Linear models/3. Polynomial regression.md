## Polynomial regression

> [!info] Polynomial regression  
> **Polynomial regression** is een uitbreiding van [[2. Linear regression#Linear regression|linear regression]] waarbij een model ook hogere machten van een of meer features gebruikt om **niet-lineaire verbanden** tussen features en een target te beschrijven.
> 
> Voor één feature $x$ en een [[1. Polynoom#Polynoom|polynoom]] van [[1. Polynoom#Graad|graad]] $d$ geldt:
> 
> $\hat{y}=b+w_1x+w_2x^2+\dots+w_dx^d$
> 
> Hierbij geldt:
> 
> - $b$ is het _intercept_.     
> - $w_1,\dots,w_d$ zijn de _model coefficients_.     
> - $d$ is de graad (_degree_) van het polynoom.     
> 
> Hoewel het verband tussen $x$ en $\hat{y}$ niet-lineair kan zijn, blijft polynomial regression een **linear model**, omdat de model coefficients lineair in de vergelijking voorkomen.
> 
> Bij meerdere features kunnen ook combinaties van features worden gebruikt, zoals $x_1x_2$.
> 
> Een hogere graad maakt complexere verbanden mogelijk, maar vergroot ook het risico op _overfitting_.

> [!example]+ Voorbeeld  
> Stel dat een model een numerieke waarde voorspelt op basis van één feature $x$.
> 
> Een linear regression model beschrijft een rechte lijn:
> 
> $\hat{y}=1+2x$
> 
> Een polynomial regression model van graad $2$ kan een kromme beschrijven:
> 
> $\hat{y}=1+2x+0{,}5x^2$
> 
> Voor $x=2$ voorspelt dit model:
> 
> $\hat{y}=1+2\cdot2+0{,}5\cdot2^2=7$
> 
> De extra term $x^2$ maakt het mogelijk dat de voorspelling niet volgens een rechte lijn verloopt.
