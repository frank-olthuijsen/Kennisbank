## Lasso regression

> [!info] Lasso regression  
> **Lasso regression** is een vorm van [[2. Linear regression#Linear regression|linear regression]] waarbij [[4. Regularization#Regularization|regularization]] wordt toegepast door de absolute waarden van de [[7. Model coefficients#Model coefficients|model coefficients]] te bestraffen.
> 
> Tijdens _training_ wordt naast de [[1. Prediction error#Prediction error|prediction error]] een **[[1. Normen#$ ell_1$-norm|L1]]-penalty** meegenomen:
> 
> $\text{loss}=\text{prediction error}+2\alpha\sum_{i=1}^{n}|\theta_i|$
> 
> N.B. $i$ start bij $1$ omdat de _bias term_ niet wordt geregulariseerd.
> 
> Hierbij bepaalt de [[2. Parameters en hyperparameters#Hyperparameters|hyperparameter]] $\alpha$ de sterkte van de regularization. Hoe groter $\alpha$, hoe sterker grote absolute waarden van de _model coefficients_ worden bestraft en hoe sterker deze richting $0$ worden gedrukt.
> 
> In tegenstelling tot [[5. Ridge regression#Ridge regression|Ridge regression]] kan Lasso regression sommige _model coefficients_ exact gelijk aan $0$ maken. De bijbehorende _features_ hebben dan geen invloed meer op de prediction. Lasso regression kan daardoor impliciet [[1. Feature engineering#Feature selection|feature selection]] uitvoeren.
> 
> Lasso regression kan hierdoor [[1. Overfitting en underfitting#Overfitting|overfitting]] verminderen. Te sterke regularization kan echter leiden tot [[1. Overfitting en underfitting#Underfitting|underfitting]].
> 
> De regularization term wordt alleen toegevoegd aan de cost function tijdens _training_, niet om de model performance te bepalen.
> 
> Een gebruikelijke vorm van de Lasso regression cost function is:
> 
> $J(\boldsymbol{\theta})=\operatorname{MSE}(\boldsymbol{\theta})+2\alpha\sum_{i=1}^{n}|\theta_i|$
> 
> Hierbij geldt:
> 
> - $\operatorname{MSE}(\boldsymbol{\theta})$ meet hoe goed het model de _training data_ fit;
>     
> - $\sum_{i=1}^{n}|\theta_i|$ is de **L1-penalty**;
>     
> - $\alpha$ bepaalt de sterkte van de regularization;
>     
> - $\theta_1,\dots,\theta_n$ zijn de _model coefficients_.
>     
> 
> Het _intercept_ $\theta_0$ wordt normaal gesproken niet meegenomen in de regularization.
> 
> De exacte schaal van de L1-penalty kan per formulering verschillen. Hier wordt $2\alpha$ gebruikt; andere bronnen en libraries kunnen een andere schaalfactor gebruiken zonder dat het principe van L1-regularization verandert.

> [!example]+ Voorbeeld  
> Stel dat een Lasso regression model twee _model coefficients_ heeft:
> 
> $\theta_1=2,\qquad\theta_2=-1$
> 
> De L1-penalty zonder de factor $2\alpha$ is:
> 
> $|\theta_1|+|\theta_2|=|2|+|-1|=3$
> 
> De bijdrage van de regularization aan de cost function is daardoor:
> 
> $2\alpha\cdot3=6\alpha$
> 
> Tijdens _training_ probeert het model daarom niet alleen de MSE te verkleinen, maar ook grote absolute waarden van de _model coefficients_ te vermijden.
> 
> Wanneer een coefficient weinig bijdraagt aan een betere fit, kan deze uiteindelijk exact $0$ worden.
