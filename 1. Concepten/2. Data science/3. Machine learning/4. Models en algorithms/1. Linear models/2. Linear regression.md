## Linear regression

> [!info] Linear regression model  
> Een **linear regression model** is een [[1. Regression|regression]] model dat een [[2. Feature, label en target#Target|target]] voorspelt als een [[3. Lineaire combinaties#Lineaire combinatie|lineaire combinatie]] van één of meer [[2. Feature, label en target#Feature|features]].
> 
> Voor $n$ features kan het model worden geschreven als:
> 
> $\hat{y}=b+w_1x_1+w_2x_2+\dots+w_nx_n$
> 
> Hierbij is $\hat{y}$ de _prediction_, $b$ het _intercept_, $x_1,\dots,x_n$ de features en $w_1,\dots,w_n$ de bijbehorende _model coefficients_.
> 
> Tijdens training worden het intercept en de model coefficients zo bepaald dat de predictions zo goed mogelijk aansluiten bij de bekende target values.

> [!example]+ Voorbeeld  
> Een linear regression model voorspelt de opnameduur van een patiënt op basis van leeftijd:
> 
> $\hat{y}=1{,}5+0{,}05x$
> 
> Voor een patiënt van $60$ jaar voorspelt het model:
> 
> $\hat{y}=1{,}5+0{,}05\cdot60=4{,}5$
> 
> De voorspelde opnameduur is dus $4{,}5$ dagen.
