## Kernel

> [!info] Kernel
> Een **kernel** is een functie die de overeenkomst tussen twee datapunten berekent. In een [[1. Support vector machine (SVM)|support vector machine (SVM)]] maakt een kernel het mogelijk om ook **niet-lineaire verbanden** te modelleren, zonder de data expliciet naar een hoger-dimensionale ruimte te transformeren. Dit wordt de *kernel trick* genoemd.

> [!example]+ Voorbeeld
> Een SVM kan met een lineaire kernel alleen een lineaire beslissingsgrens bepalen. Met een [[3. Radial basis function|radial basis function (RBF)]] als kernel kan de SVM ook niet-lineaire beslissingsgrenzen vormen.
