## Instance-based learning

> [!info] Instance-based learning  
> **Instance-based learning** is een leermethode waarbij een machine-learningsysteem de trainingsvoorbeelden bewaart en nieuwe waarnemingen beoordeelt door deze te vergelijken met vergelijkbare voorbeelden uit de trainingsdata.
> 
> Hiervoor wordt een [[1. Similarity function#Similarity function|similarity function]] of [[2. Distance function#Distance function|distance function]] gebruikt om te bepalen welke opgeslagen waarnemingen het meest op de nieuwe waarneming lijken.
> 
> Het systeem generaliseert dus voornamelijk door **vergelijking met eerdere voorbeelden**, in plaats van eerst een algemeen model uit de trainingsdata af te leiden.
> 
> Instance-based learning kan geschikt zijn voor relatief kleine datasets en situaties waarin nieuwe trainingsdata gemakkelijk moeten kunnen worden toegevoegd. Daar staat tegenover dat voor het maken van voorspellingen vaak veel trainingsdata beschikbaar moet blijven en veel vergelijkingen nodig kunnen zijn. Hierdoor kan deze aanpak minder goed schalen.
> 
> Bij data met zeer veel features kan het bovendien moeilijker worden om betekenisvolle overeenkomsten of afstanden tussen waarnemingen te bepalen.

> [!example]+ Voorbeeld  
> Bij **k-nearest neighbors regression** worden voor een nieuwe waarneming de $k$ meest vergelijkbare trainingswaarnemingen gezocht.
> 
> De voorspelde target wordt vervolgens bijvoorbeeld bepaald door het gemiddelde te nemen van de targetwaarden van deze $k$ dichtstbijzijnde waarnemingen.
## Model-based learning

> [!info] Model-based learning  
> **Model-based learning** is een leermethode waarbij uit de trainingsdata een [[1. Model#Model|model]] wordt geleerd dat algemene verbanden in de data probeert te beschrijven.
> 
> Tijdens [[1. Training|training]] zoekt een **training algorithm** naar geschikte waarden voor de **modelparameters**. Daarbij wordt bijvoorbeeld een [[2. Loss function#Loss function|loss function]] geminimaliseerd of een [[1. Utility function#Utility function|utility function]] gemaximaliseerd.
> 
> Het getrainde model kan vervolgens tijdens [[4. Inference#Inference|inference]] worden gebruikt om voorspellingen te doen voor nieuwe, onbekende waarnemingen.
> 
> Model-based learning generaliseert dus door een algemeen model uit de trainingsvoorbeelden af te leiden, in tegenstelling tot [[2. Instance-based en model-based learning|instance-based learning]], waarbij nieuwe waarnemingen rechtstreeks met opgeslagen trainingsvoorbeelden worden vergeleken.

> [!example]+ Voorbeeld  
> Bij **linear regression** wordt een [[2. Linear regression#Linear regression model|lineair model]] gekozen. De modelparameters kunnen bijvoorbeeld worden weergegeven als $\theta_0, \theta_1, \ldots, \theta_n$.
> 
> Tijdens training worden waarden voor deze parameters gezocht waarmee de loss zo klein mogelijk wordt. Bij **ordinary least squares** gebeurt dit door de **residual sum of squares** te minimaliseren.
> 
> In scikit-learn worden de parameters geleerd wanneer `fit()` wordt uitgevoerd:
> 
> ```python
> from sklearn.linear_model import LinearRegression
> 
> model = LinearRegression()
> model.fit(X, y)
> ```
> 
> Daarna kan het getrainde model tijdens inference voorspellingen voor nieuwe waarnemingen maken.
