> [!info] Model selection  
> **Model selection** is het proces waarbij uit meerdere kandidaatmodellen of modelconfiguraties het model wordt gekozen waarvan wordt verwacht dat het het beste generaliseert naar nieuwe data.
> 
> Kandidaten kunnen bijvoorbeeld verschillen in:
> 
> - het gebruikte modeltype of algoritme.     
> - de gekozen [[2. Parameters en hyperparameters#Hyperparameters|hyperparameters]].     
> - de [[3. Model complexity en dataset size#Model complexity|model complexity]].     
> 
> De kandidaten worden vergeleken met [[1. Training, validation en test set#Validation set|validation data]], bijvoorbeeld via een vaste validation set of [[3. Cross-validation|cross-validation]].
> 
> De [[1. Training, validation en test set#Test set|test set]] wordt **niet gebruikt voor model selection**. Deze blijft apart en wordt pas gebruikt om de prestaties van het uiteindelijk gekozen model op onbekende data te schatten.

## Proces

Een gebruikelijke werkwijze is:

1. Kies een aantal kandidaatmodellen of modelconfiguraties.    
2. Train deze op dezelfde [[1. Training, validation en test set#Training set|training data]].    
3. Beoordeel de modellen op validation data met een geschikte performance metric.    
4. Kies het model dat, rekening houdend met de eisen van het probleem, het beste presteert.    
5. Train de gekozen modelconfiguratie eventueel opnieuw op alle beschikbare training- en validation data.    
6. Evalueer het uiteindelijke model één keer op de test set.    

Wanneer alleen verschillende hyperparameters van hetzelfde modeltype worden vergeleken, spreken we specifieker van [[2. Hyperparameter tuning|hyperparameter tuning]].

## Overwegingen

Welke modellen goede kandidaten zijn, hangt onder andere af van:
### Hoeveelheid data
    
- Sommige modellen kunnen goed werken met relatief weinig data, terwijl andere juist sterk profiteren van grote datasets.        
- SVMs kunnen bijvoorbeeld geschikt zijn voor kleine tot middelgrote datasets.        
- Neural networks hebben doorgaans meer data nodig om goed te generaliseren.
### Domeinkennis
    
- Kennis over het probleem kan helpen om geschikte modellen te kiezen.        
- Als bijvoorbeeld een lineair verband wordt verwacht, is het logisch om eerst een eenvoudig lineair model te onderzoeken.
### Performance metric
    
- Het beste model is niet automatisch het model met de hoogste [[2. Accuracy#Accuracy|accuracy]].        
- Welke metric belangrijk is, hangt af van de gevolgen van verschillende soorten fouten.        
- Bij medische screening kan bijvoorbeeld [[3. Precision, recall en specificity#Recall|recall]] belangrijk zijn wanneer het missen van een patiënt met een aandoening ernstige gevolgen heeft.
### Explainability
    
- Soms moet duidelijk kunnen worden gemaakt waarom een model een bepaalde voorspelling doet.        
- Decision trees en lineaire modellen zijn relatief goed uitlegbaar.        
- Neural networks zijn doorgaans minder transparant.

> [!example]+ Voorbeeld  
> Een ziekenhuis wil voorspellen welke patiënten een verhoogd risico hebben op heropname.
> 
> Er worden drie kandidaatmodellen onderzocht:
> 
> - logistic regression;
> - een decision tree;
> - een neural network.
> 
> Alle modellen worden op dezelfde training data getraind en met cross-validation beoordeeld.
> 
> Het ziekenhuis kiest vooraf een geschikte performance metric op basis van wat in de praktijk belangrijk is. Vervolgens wordt het model gekozen dat daarop het beste presteert, waarbij ook zaken als uitlegbaarheid en complexiteit kunnen meewegen.
> 
> Pas nadat het model is gekozen, wordt de test set gebruikt om te beoordelen hoe goed het uiteindelijke model naar nieuwe patiënten generaliseert.
