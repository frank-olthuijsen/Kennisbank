
- Hold out part of the training set, thereby creating a reduced training set and  a **validation set** (or **development set** or **dev set**).
- Train multiple models with various hyperparameters on the reduced training set.
- Select the model that performs best on the validation set.
- Then train the model on the full training set (reduced training + validation).
- Evaluate the model on the test set to get an estimate of the generalization error.

> [!info] Holdout validation  
> **Holdout validation** is een validatiemethode waarbij een deel van de beschikbare trainingsdata **apart wordt gehouden als validation set**.
> 
> Het model wordt getraind op de overgebleven training set en vervolgens beoordeeld op deze validation set. De validation set kan worden gebruikt om bijvoorbeeld verschillende modellen of [[2. Parameters en hyperparameters#Hyperparameters|hyperparameters]] met elkaar te vergelijken.
> 
> Bij holdout validation wordt hiervoor **één vaste splitsing** gebruikt. Dit verschilt van [[3. Cross-validation|cross-validation]], waarbij meerdere verschillende train/validation-splits worden gebruikt.
> 
> De test set blijft buiten dit proces en wordt pas gebruikt voor de uiteindelijke evaluatie van het gekozen model.
>
> Engels ook; **validation set**, **development set**, **dev set**

> [!example]+ Voorbeeld  
> Een ziekenhuis heeft gegevens van **10.000 patiënten** beschikbaar.
> 
> Eerst worden bijvoorbeeld 2.000 patiëntrecords apart gehouden als **test set**. Deze worden tijdens de ontwikkeling van het model niet gebruikt.
> 
> De resterende 8.000 records worden gebruikt voor modelontwikkeling. Bij holdout validation worden deze bijvoorbeeld verdeeld in:
> 
> - 6.400 records als **training set**;
> - 1.600 records als **validation set**.
> 
> Verschillende modellen of hyperparameterinstellingen worden op de training set getraind en op de validation set beoordeeld.
> 
> Nadat het model is gekozen, wordt de **test set** gebruikt om de uiteindelijke prestaties op onbekende data te schatten.
