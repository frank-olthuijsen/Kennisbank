## Training logistic regression with batch gradient descent

Een [[1. Logistic regression#Logistic regression|logistic regression]] model kan worden getraind met [[1. Gradient descent#Batch gradient descent|batch gradient descent]] door de _model parameters_ $\boldsymbol{\theta}$ iteratief aan te passen zodat de _cost function_ steeds kleiner wordt.

Bij logistic regression wordt hiervoor [[15. Log loss#Log loss|log loss]] gebruikt. Voor $m$ _observations_ geldt:

$J(\boldsymbol{\theta})=-\frac{1}{m}\sum_{i=1}^{m}\left[y^{(i)}\log\left(\hat{p}^{(i)}\right)+\left(1-y^{(i)}\right)\log\left(1-\hat{p}^{(i)}\right)\right]$

Hierbij is:

- $J(\boldsymbol{\theta})$ de gemiddelde _log loss_ voor de huidige _model parameters_;
    
- $m$ het aantal _observations_;
    
- $y^{(i)}\in{0,1}$ de werkelijke _class_ van observation $i$;
    
- $\hat{p}^{(i)}$ de _estimated probability_ dat observation $i$ tot de positieve _class_ behoort.
    

Voor iedere observation wordt deze _estimated probability_ berekend met de [[13. Logistische functie#Logistische functie|logistic function]]:

$\hat{p}^{(i)}=\sigma\left(\boldsymbol{\theta}^{\mathrm T}\mathbf{x}^{(i)}\right)$

Het doel van _training_ is waarden voor $\boldsymbol{\theta}$ te vinden waarvoor $J(\boldsymbol{\theta})$ zo klein mogelijk is.

### 1. Initialiseer de model parameters

Begin met initiële waarden voor de _model parameters_:

$\boldsymbol{\theta}=\begin{pmatrix}\theta_0\\ \theta_1\\ \vdots\\ \theta_n\end{pmatrix}$

### 2. Bereken de estimated probabilities

Voor iedere _observation_ wordt eerst de lineaire score berekend:

$t^{(i)}=\boldsymbol{\theta}^{\mathrm T}\mathbf{x}^{(i)}$

Deze [[14. Logit#Logit|logit]] wordt met de [[13. Logistische functie#Logistische functie|logistic function]] omgezet naar een _estimated probability_:

$\hat{p}^{(i)}=\sigma\left(t^{(i)}\right)=\frac{1}{1+e^{-t^{(i)}}}$

### 3. Bereken de log loss

Met de _estimated probabilities_ en de werkelijke _classes_ wordt de gemiddelde _log loss_ over de volledige _training set_ berekend:

$J(\boldsymbol{\theta})=-\frac{1}{m}\sum_{i=1}^{m}\left[y^{(i)}\log\left(\hat{p}^{(i)}\right)+\left(1-y^{(i)}\right)\log\left(1-\hat{p}^{(i)}\right)\right]$

Hoe kleiner deze waarde, hoe beter de _estimated probabilities_ overeenkomen met de werkelijke _classes_.

### 4. Bereken de gradient

Om te bepalen in welke richting de _model parameters_ moeten worden aangepast, wordt berekend hoe de _log loss_ verandert wanneer iedere afzonderlijke parameter verandert.

Voor iedere parameter $\theta_j$ geldt:

$\frac{\partial J}{\partial\theta_j}=\frac{1}{m}\sum_{i=1}^{m}\left(\hat{p}^{(i)}-y^{(i)}\right)x_j^{(i)}$
  
- $j$ is de index van een _model parameter_ en bepaalt voor welke parameter $\theta_j$ de afgeleide wordt berekend;    
- $x_j^{(i)}$ is de waarde van feature $j$ van observation $i$.    

De partiële afgeleide:

$\frac{\partial J}{\partial\theta_j}$

geeft aan hoe $J(\boldsymbol{\theta})$ verandert wanneer alleen parameter $\theta_j$ een kleine hoeveelheid verandert, terwijl de andere parameters constant worden gehouden.

Omdat het model meerdere parameters heeft, wordt voor iedere parameter zo'n partiële afgeleide berekend. Samen vormen deze waarden de [[2. Gradiënt#Gradiënt|gradient vector]]:

$\nabla_{\boldsymbol{\theta}}J(\boldsymbol{\theta})=\begin{pmatrix}\frac{\partial J}{\partial\theta_0}\\ \frac{\partial J}{\partial\theta_1}\\ \vdots\\ \frac{\partial J}{\partial\theta_n}\end{pmatrix}$

Iedere partiële afgeleide is dus één component van de gradient vector en hoort bij één _model parameter_.

In vectorized form kan dezelfde gradient worden geschreven als:

$\nabla_{\boldsymbol{\theta}}J(\boldsymbol{\theta})=\frac{1}{m}X^{\mathrm T}\left(\hat{\mathbf{p}}-\mathbf{y}\right)$

De gradient vector wijst in de richting waarin de _cost function_ het snelst toeneemt. Om de _log loss_ te verkleinen, worden de _model parameters_ daarom in de tegenovergestelde richting aangepast.

Omdat bij **batch gradient descent** alle $m$ _observations_ worden gebruikt, is iedere gradient gebaseerd op de volledige _training set_.

### 5. Update de model parameters

De parameters worden aangepast in de tegengestelde richting van de gradient:

$\boldsymbol{\theta}_{\mathrm{next}}=\boldsymbol{\theta}-\eta\nabla_{\boldsymbol{\theta}}J(\boldsymbol{\theta})$

Hierbij is $\eta$ de _learning rate_.

De gradient vector bevat voor iedere parameter de richting en grootte van de benodigde verandering. De _learning rate_ bepaalt vervolgens hoe groot de daadwerkelijke stap in die richting wordt.

Je trekt dus van iedere parameter de learning rate maal zijn partiële afgeleide af.

### 6. Herhaal

Het trainingsproces wordt iteratief herhaald:

```
initialiseer θ
    ↓
bereken logits voor volledige training set
    ↓
bereken estimated probabilities
    ↓
bereken log loss
    ↓
bereken gradient over volledige training set
    ↓
update θ
    ↓
herhaal
```

Bij batch gradient descent wordt per [[5. Epoch#Epoch|epoch]] de volledige _training set_ verwerkt en vindt vervolgens één parameterupdate plaats.

Door dit proces te herhalen, worden de _model parameters_ aangepast in de richting waarin de log loss afneemt.
