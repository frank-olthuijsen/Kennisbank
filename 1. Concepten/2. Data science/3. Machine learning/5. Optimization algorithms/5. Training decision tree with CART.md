## Training decision tree with CART

Een [[1. Decision tree#Decision tree|decision tree]] kan worden getraind met het **Classification and Regression Tree (CART)**-algoritme.

CART bouwt een _decision tree_ op door de _training data_ herhaaldelijk in twee groepen te splitsen. Bij iedere _node_ zoekt het algoritme naar de combinatie van een _feature_ en een _threshold_ die volgens een gekozen criterium de beste splitsing oplevert.

Het criterium hangt af van de _task_:

- bij [[1. Classification#Classification|classification]] kan [[2. Gini impurity#Gini impurity|Gini impurity]] worden gebruikt om _nodes_ te creëren waarin de _classes_ zo zuiver mogelijk zijn;    
- bij [[1. Regression#Regression|regression]] kan [[3. MSE#Mean Squared Error (MSE)|MSE]] worden gebruikt om _nodes_ te creëren waarin de _target values_ zo dicht mogelijk bij elkaar liggen.    

CART is een _greedy algorithm_: bij iedere _node_ wordt de op dat moment beste splitsing gekozen, zonder te onderzoeken of een andere keuze uiteindelijk tot een betere volledige boom zou leiden.

### 1. Initialiseer de root node

Het algoritme begint met een _root node_ die alle _training observations_ bevat.

Vervolgens wordt gezocht naar de beste manier om deze _observations_ in twee child nodes te verdelen.

### 2. Bepaal mogelijke splitsingen

Voor iedere _feature_ onderzoekt CART mogelijke _thresholds_.

Bij een numerieke _feature_ kan een mogelijke splitsing bijvoorbeeld zijn:

`leeftijd <= 65`

De _observations_ worden daarmee verdeeld over:

- **left node:** _observations_ waarvoor de voorwaarde waar is;    
- **right node:** _observations_ waarvoor de voorwaarde niet waar is.    

Iedere combinatie van een _feature_ $k$ en een _threshold_ $t_k$ levert een mogelijke splitsing op.

### 3. Beoordeel de mogelijke splitsingen

#### Classification

Bij _classification_ kan de _Gini impurity_ van iedere child node worden berekend.

De cost van een mogelijke splitsing is vervolgens de gewogen gemiddelde _Gini impurity_ van beide child nodes:

$J(k,t_k)=\frac{m_{\mathrm{left}}}{m}G_{\mathrm{left}}+\frac{m_{\mathrm{right}}}{m}G_{\mathrm{right}}$

waarbij:

- $m$ het aantal _observations_ in de huidige _node_ is;    
- $m_{\mathrm{left}}$ en $m_{\mathrm{right}}$ het aantal _observations_ in de twee child nodes zijn;    
- $G_{\mathrm{left}}$ en $G_{\mathrm{right}}$ hun _Gini impurity_ zijn.    

Een lage waarde betekent dat de child nodes relatief zuivere _class distributions_ bevatten.

#### Regression

Bij _regression_ bevat iedere _observation_ een numerieke _target value_ $y^{(i)}$.

Voor iedere mogelijke splitsing berekent CART de MSE van beide child nodes en gebruikt het de volgende cost function:

$J(k,t_k)=\frac{m_{\mathrm{left}}}{m}\operatorname{MSE}_{\mathrm{left}}+\frac{m_{\mathrm{right}}}{m}\operatorname{MSE}_{\mathrm{right}}$

Voor iedere node geldt:

$\operatorname{MSE}_{\mathrm{node}}=\frac{\sum_{i\in\mathrm{node}}\left(\hat{y}_{\mathrm{node}}-y^{(i)}\right)^2}{m_{\mathrm{node}}}$

waarbij de prediction van de node het gemiddelde is van de _target values_ van de _training observations_ in die node:

$\hat{y}_{\mathrm{node}}=\frac{\sum_{i\in\mathrm{node}}y^{(i)}}{m_{\mathrm{node}}}$

Hierbij is:

- $m_{\mathrm{node}}$ het aantal _training observations_ in de node;    
- $y^{(i)}$ de werkelijke _target value_ van observation $i$;    
- $\hat{y}_{\mathrm{node}}$ de gemiddelde _target value_ van de node;    
- $\operatorname{MSE}_{\mathrm{node}}$ de gemiddelde gekwadrateerde afwijking van de _target values_ ten opzichte van dit gemiddelde.    

Een lage MSE betekent dus dat de _target values_ binnen een node relatief dicht bij elkaar liggen.

CART zoekt bij _regression_ daarom naar een splitsing die twee child nodes oplevert waarvan de gewogen gemiddelde MSE zo klein mogelijk is.

### 4. Selecteer de beste splitsing

CART kiest de combinatie van _feature_ $k$ en _threshold_ $t_k$ waarvoor de cost function minimaal is:

$(k^*,t^*_k)=\arg\min_{k,t_k}J(k,t_k)$

Bij _classification_ betekent dit dat de child nodes zo zuiver mogelijke _class distributions_ krijgen.

Bij _regression_ betekent dit dat de _target values_ binnen de child nodes zo weinig mogelijk rond hun gemiddelde variëren.

De huidige _node_ wordt vervolgens op basis van deze combinatie gesplitst.

### 5. Herhaal voor de nieuwe nodes

Voor iedere nieuwe child node wordt hetzelfde proces recursief herhaald:

1. bepaal mogelijke splitsingen;    
2. bereken voor iedere splitsing de bijbehorende cost;    
3. selecteer de splitsing met de laagste cost;    
4. verdeel de _observations_ over twee nieuwe child nodes.    

Hierdoor groeit de boom steeds verder.

### 6. Stop met splitsen

Een _node_ wordt een _leaf node_ wanneer deze niet verder wordt gesplitst.

Dit kan bijvoorbeeld gebeuren wanneer:

- geen verdere geldige splitsing mogelijk is;    
- een ingestelde maximale boomdiepte is bereikt;    
- een minimumaantal _observations_ voor verdere splitsing niet wordt gehaald;    
- verdere splitsing onvoldoende verbetering oplevert.    

### 7. Bepaal de prediction van een leaf node

Wanneer een nieuwe _observation_ door de getrainde tree wordt geleid, eindigt deze in een _leaf node_.

Bij _classification_ wordt de _class prediction_ doorgaans bepaald door de _class_ die het meest voorkomt onder de _training observations_ in die leaf node. De verdeling over de _classes_ kan daarnaast worden gebruikt voor _estimated probabilities_.

Bij _regression_ is de prediction het gemiddelde van de _target values_ van de _training observations_ in de leaf node:

$\hat{y}_{\mathrm{leaf}}=\frac{1}{m_{\mathrm{leaf}}}\sum_{i\in\mathrm{leaf}}y^{(i)}$

### 8. Overzicht

```
initialiseer root node met training data
    ↓
onderzoek mogelijke features en thresholds
    ↓
bereken cost van iedere mogelijke splitsing
    ↓
classification → gewogen impurity
regression     → gewogen MSE
    ↓
selecteer de splitsing met de laagste cost
    ↓
verdeel observations over twee child nodes
    ↓
herhaal recursief
    ↓
leaf nodes
    ↓
classification → class / estimated probabilities
regression     → gemiddelde target value
```

In tegenstelling tot bijvoorbeeld _gradient descent_ optimaliseert CART niet één globale verzameling model parameters door deze herhaaldelijk bij te werken. De boom wordt stap voor stap opgebouwd door bij iedere _node_ lokaal de beste splitsing te kiezen.
