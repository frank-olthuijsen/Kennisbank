## Training softmax regression with batch gradient descent

Een [[4. Softmax regression#Softmax regression|softmax regression]] model kan worden getraind met [[1. Gradient descent#Batch gradient descent|batch gradient descent]] door de _model parameters_ iteratief aan te passen zodat de [[3. Cross-entropy#Cross-entropy|cross-entropy cost function]] steeds kleiner wordt.

Softmax regression heeft voor iedere class $k$ een afzonderlijke parameter vector $\boldsymbol{\theta}^{(k)}$. Samen vormen deze de parameter matrix:

$\boldsymbol{\Theta}=[\boldsymbol{\theta}^{(1)}\ \boldsymbol{\theta}^{(2)}\ \cdots\ \boldsymbol{\theta}^{(K)}]$

Voor $m$ _observations_ en $K$ _classes_ wordt de _cross-entropy cost function_ gegeven door:

$J(\boldsymbol{\Theta})=-\frac{1}{m}\sum_{i=1}^{m}\sum_{k=1}^{K}y_k^{(i)}\log\left(\hat{p}_k^{(i)}\right)$

Hierbij is:

- $J(\boldsymbol{\Theta})$ de gemiddelde _cross-entropy loss_ voor de huidige _model parameters_;    
- $m$ het aantal _observations_;    
- $K$ het aantal _classes_;    
- $y_k^{(i)}=1$ wanneer observation $i$ tot class $k$ behoort en anders $0$;    
- $\hat{p}_k^{(i)}$ de [[3. Estimated probability#Estimated probability|estimated probability]] dat observation $i$ tot class $k$ behoort.    

Omdat voor iedere observation slechts één werkelijke class geldt, is slechts één waarde $y_k^{(i)}$ gelijk aan $1$. Voor die observation blijft daardoor alleen de term voor de werkelijke class over. Een hoge _estimated probability_ voor de juiste class geeft een lage _loss_; een lage _estimated probability_ voor de juiste class geeft een hoge _loss_.

Het doel van _training_ is waarden voor $\boldsymbol{\Theta}$ te vinden waarvoor $J(\boldsymbol{\Theta})$ zo klein mogelijk is.

### 1. Initialiseer de model parameters

Voor iedere class $k$ wordt een parameter vector $\boldsymbol{\theta}^{(k)}$ geïnitialiseerd.

Het model heeft dus niet één parameter vector, zoals bij binary logistic regression, maar $K$ parameter vectors:

$\boldsymbol{\Theta}=[\boldsymbol{\theta}^{(1)}\ \boldsymbol{\theta}^{(2)}\ \cdots\ \boldsymbol{\theta}^{(K)}]$

### 2. Bereken de scores en estimated probabilities

Voor iedere observation $i$ berekent het model voor iedere class $k$ een score:

$s_k(\mathbf{x}^{(i)})=(\boldsymbol{\theta}^{(k)})^{\mathrm T}\mathbf{x}^{(i)}$

De scores voor alle $K$ classes vormen samen de scorevector $\mathbf{s}(\mathbf{x}^{(i)})$.

De [[4. Softmax function#Softmax function|softmax function]] zet deze scorevector om in _estimated probabilities_:

$\hat{p}_k^{(i)}=\sigma(\mathbf{s}(\mathbf{x}^{(i)}))_k$

Voor iedere observation ontstaan daardoor $K$ _estimated probabilities_ die samen optellen tot $1$.

### 3. Bereken de cross-entropy loss

Met de _estimated probabilities_ en de werkelijke _classes_ wordt de gemiddelde _cross-entropy loss_ over de volledige _training set_ berekend:

$J(\boldsymbol{\Theta})=-\frac{1}{m}\sum_{i=1}^{m}\sum_{k=1}^{K}y_k^{(i)}\log\left(\hat{p}_k^{(i)}\right)$

De _cost function_ wordt kleiner wanneer het model een hogere _estimated probability_ toekent aan de werkelijke class van iedere observation.

### 4. Bereken de gradients

Omdat iedere class een eigen parameter vector $\boldsymbol{\theta}^{(k)}$ heeft, wordt voor iedere class een afzonderlijke [[2. Gradiënt#Gradiënt|gradient vector]] berekend:

$\nabla_{\boldsymbol{\theta}^{(k)}}J(\boldsymbol{\Theta})=\frac{1}{m}\sum_{i=1}^{m}\left(\hat{p}_k^{(i)}-y_k^{(i)}\right)\mathbf{x}^{(i)}$

De term:

$\hat{p}_k^{(i)}-y_k^{(i)}$

is de prediction error voor class $k$ bij observation $i$.

Voor de werkelijke class geldt $y_k^{(i)}=1$. Wanneer de _estimated probability_ voor die class te laag is, is deze fout negatief en zorgt de parameterupdate ervoor dat de score voor deze class wordt verhoogd.

Voor de overige classes geldt $y_k^{(i)}=0$. Een te hoge _estimated probability_ voor zo'n class levert een positieve fout op en zorgt ervoor dat de score voor die class wordt verlaagd.

Omdat bij **batch gradient descent** alle $m$ _observations_ worden gebruikt, is iedere gradient gebaseerd op de volledige _training set_.

In vectorized form kunnen de gradients voor alle classes tegelijk worden geschreven als:

$\nabla_{\boldsymbol{\Theta}}J(\boldsymbol{\Theta})=\frac{1}{m}X^{\mathrm T}(\hat{P}-Y)$

Hierbij bevatten $\hat{P}$ en $Y$ respectievelijk de _estimated probabilities_ en werkelijke class-indicatoren voor alle observations en classes.

De parameter vectors van de verschillende classes worden niet onafhankelijk van elkaar getraind: iedere _estimated probability_ wordt door de softmax function berekend op basis van de scores van alle classes.

### 5. Update de model parameters

Voor iedere class $k$ wordt de parameter vector aangepast in de tegengestelde richting van zijn gradient:

$\boldsymbol{\theta}_{\mathrm{next}}^{(k)}=\boldsymbol{\theta}^{(k)}-\eta\nabla_{\boldsymbol{\theta}^{(k)}}J(\boldsymbol{\Theta})$

Hierbij is $\eta$ de _learning rate_.

Dit gebeurt voor alle $K$ parameter vectors. Samen vormt dit de update van de volledige parameter matrix $\boldsymbol{\Theta}$.

### 6. Herhaal

Het trainingsproces wordt iteratief herhaald:

```
initialiseer Θ
    ↓
bereken class scores voor volledige training set
    ↓
bereken estimated probabilities met softmax
    ↓
bereken cross-entropy loss
    ↓
bereken gradient voor iedere class
    ↓
update Θ
    ↓
herhaal
```

Bij batch gradient descent wordt per [[5. Epoch#Epoch|epoch]] de volledige _training set_ verwerkt en vindt vervolgens één update van de parameter matrix plaats.

Door dit proces te herhalen, worden de _model parameters_ aangepast in de richting waarin de _cross-entropy loss_ afneemt.
