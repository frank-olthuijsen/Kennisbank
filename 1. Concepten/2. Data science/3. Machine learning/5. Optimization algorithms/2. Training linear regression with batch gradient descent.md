## Training linear regression with batch gradient descent

Een [[2. Linear regression#Linear regression|linear regression]] model kan worden getraind met [[1. Gradient descent#Batch gradient descent|batch gradient descent]] door de _model parameters_ $\vec{\theta}$ iteratief aan te passen zodat de _cost function_ steeds kleiner wordt.

Bij linear regression kan [[3. MSE#Mean Squared Error (MSE)|MSE]] als _cost function_ worden gebruikt. Voor:

$h_{\vec{\theta}}(\vec{x})=\vec{\theta}^{\mathrm{T}}\vec{x}$

geldt:

$\operatorname{MSE}(X,y,h_{\vec{\theta}})=\frac{1}{m}\sum_{i=1}^{m}\left(\vec{\theta}^{\mathrm{T}}\vec{x}^{(i)}-y^{(i)}\right)^2$

Hierbij bepaalt $\vec{\theta}$ het model. Het doel van _training_ is waarden voor $\vec{\theta}$ te vinden waarvoor de MSE zo klein mogelijk is.

### 1. Initialiseer de model parameters

Begin met initiële waarden voor:

$\vec{\theta}=\begin{pmatrix}\theta_0\\ \theta_1\\ \vdots\\ \theta_n\end{pmatrix}$

Deze waarden kunnen bijvoorbeeld willekeurig worden gekozen.

### 2. Bereken de predictions

Voor iedere _observation_ wordt met de huidige _model parameters_ een _prediction_ berekend:

$\hat{y}^{(i)}=\vec{\theta}^{\mathrm{T}}\vec{x}^{(i)}$

Hieruit volgen de _prediction errors_:

$\hat{y}^{(i)}-y^{(i)}$

### 3. Bereken de gradient

De [[2. Gradiënt#Gradiënt|gradient]] geeft aan hoe de MSE verandert wanneer de afzonderlijke _model parameters_ worden veranderd.

Voor parameter $\theta_j$ geldt:

$\frac{\partial}{\partial\theta_j}\operatorname{MSE}(X,y,h_{\vec{\theta}})=\frac{2}{m}\sum_{i=1}^{m}\left(\vec{\theta}^{\mathrm{T}}\vec{x}^{(i)}-y^{(i)}\right)x_j^{(i)}$

Omdat bij **batch gradient descent** alle $m$ _observations_ in deze som worden gebruikt, wordt iedere parameterupdate gebaseerd op de volledige _training set_.

Voor alle parameters tegelijk kan de gradient in vectorized form worden geschreven als:

$\nabla_{\vec{\theta}}\operatorname{MSE}(X,y,h_{\vec{\theta}})=\frac{2}{m}X^{\mathrm{T}}\left(X\vec{\theta}-y\right)$

### 4. Update de model parameters

De _model parameters_ worden vervolgens aangepast in de tegengestelde richting van de gradient:

$\vec{\theta}_{\mathrm{next}}=\vec{\theta}-\eta\nabla_{\vec{\theta}}\operatorname{MSE}(X,y,h_{\vec{\theta}})$

Hierbij is $\eta$ de _learning rate_.

De gradient wijst in de richting waarin de MSE het snelst toeneemt. Door deze van $\vec{\theta}$ af te trekken, bewegen de _model parameters_ dus in de richting waarin de MSE afneemt.

### 5. Herhaal

Het proces wordt iteratief herhaald:

```
initialiseer θ
    ↓
bereken predictions voor volledige training set
    ↓
bereken MSE
    ↓
bereken gradient over volledige training set
    ↓
update θ
    ↓
herhaal
```

Bij batch gradient descent wordt per [[5. Epoch#Epoch|epoch]] de volledige _training set_ gebruikt en vindt vervolgens één parameterupdate plaats.

Wanneer de updates convergeren, nadert $\vec{\theta}$ de parameterwaarden waarvoor de MSE minimaal is.
