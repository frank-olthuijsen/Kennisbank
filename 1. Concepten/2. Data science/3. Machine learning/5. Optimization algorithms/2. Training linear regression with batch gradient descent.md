## Training linear regression with batch gradient descent

Een [[2. Linear regression#Linear regression|linear regression]] model kan worden getraind met [[1. Gradient descent#Batch gradient descent|batch gradient descent]] door de _model parameters_ $\vec{\theta}$ iteratief aan te passen zodat de _cost function_ steeds kleiner wordt.

Bij linear regression kan [[3. MSE#Mean Squared Error (MSE)|MSE]] als _cost function_ worden gebruikt. Voor $m$ _observations_ geldt:

$J(\vec{\theta})=\operatorname{MSE}(X,y,h_{\vec{\theta}})=\frac{1}{m}\sum_{i=1}^{m}\left(\vec{\theta}^{\mathrm T}\vec{x}^{(i)}-y^{(i)}\right)^2$

Hierbij is:

- $J(\vec{\theta})$ de gemiddelde _MSE_ voor de huidige _model parameters_;    
- $m$ het aantal _observations_;    
- $y^{(i)}$ de werkelijke _target value_ van observation $i$;    
- $\vec{\theta}^{\mathrm T}\vec{x}^{(i)}$ de _prediction_ voor observation $i$.    

Voor iedere observation wordt deze _prediction_ berekend met:

$\hat{y}^{(i)}=h_{\vec{\theta}}\left(\vec{x}^{(i)}\right)=\vec{\theta}^{\mathrm T}\vec{x}^{(i)}$

Het doel van _training_ is waarden voor $\vec{\theta}$ te vinden waarvoor $J(\vec{\theta})$ zo klein mogelijk is.

### 1. Initialiseer de model parameters

Begin met initiële waarden voor de _model parameters_:

$\vec{\theta}=\begin{pmatrix}\theta_0\\ \theta_1\\ \vdots\\ \theta_n\end{pmatrix}$

Deze waarden kunnen bijvoorbeeld willekeurig worden gekozen.

### 2. Bereken de predictions

Voor iedere _observation_ wordt met de huidige _model parameters_ een _prediction_ berekend:

$\hat{y}^{(i)}=\vec{\theta}^{\mathrm T}\vec{x}^{(i)}$

Het verschil tussen de _prediction_ en de werkelijke _target value_ is de _prediction error_:

$\hat{y}^{(i)}-y^{(i)}$

Deze _prediction errors_ bepalen hoeveel iedere observation bijdraagt aan de MSE.

### 3. Bereken de MSE

Met de _predictions_ en de werkelijke _target values_ wordt de gemiddelde MSE over de volledige _training set_ berekend:

$J(\vec{\theta})=\frac{1}{m}\sum_{i=1}^{m}\left(\hat{y}^{(i)}-y^{(i)}\right)^2$

Hoe kleiner deze waarde, hoe dichter de _predictions_ gemiddeld bij de werkelijke _target values_ liggen.

Omdat de _prediction errors_ worden gekwadrateerd, dragen grotere fouten relatief zwaar bij aan de _cost function_.

### 4. Bereken de gradient

Om te bepalen in welke richting de _model parameters_ moeten worden aangepast, wordt berekend hoe de MSE verandert wanneer iedere afzonderlijke parameter verandert.

Voor iedere parameter $\theta_j$ geldt:

$\frac{\partial J}{\partial\theta_j}=\frac{2}{m}\sum_{i=1}^{m}\left(\vec{\theta}^{\mathrm T}\vec{x}^{(i)}-y^{(i)}\right)x_j^{(i)}$

- $j$ is de index van een _model parameter_ en bepaalt voor welke parameter $\theta_j$ de afgeleide wordt berekend;    
- $x_j^{(i)}$ is de waarde van feature $j$ van observation $i$.    

De partiële afgeleide:

$\frac{\partial J}{\partial\theta_j}$

geeft aan hoe $J(\vec{\theta})$ verandert wanneer alleen parameter $\theta_j$ een kleine hoeveelheid verandert, terwijl de andere parameters constant worden gehouden.

Omdat het model meerdere parameters heeft, wordt voor iedere parameter zo'n partiële afgeleide berekend. Samen vormen deze waarden de [[2. Gradiënt#Gradiënt|gradiënt]], oftewel de _gradient vector_:

$\nabla_{\vec{\theta}}J(\vec{\theta})=\begin{pmatrix}\frac{\partial J}{\partial\theta_0}\\ \frac{\partial J}{\partial\theta_1}\\ \vdots\\ \frac{\partial J}{\partial\theta_n}\end{pmatrix}$

Iedere partiële afgeleide is dus één component van de _gradient vector_ en hoort bij één _model parameter_.

In vectorized form kan dezelfde gradient worden geschreven als:

$\nabla_{\vec{\theta}}J(\vec{\theta})=\frac{2}{m}X^{\mathrm T}\left(X\vec{\theta}-y\right)$

De _gradient vector_ wijst in de richting waarin de _cost function_ het snelst toeneemt. Om de MSE te verkleinen, worden de _model parameters_ daarom in de tegenovergestelde richting aangepast.

Omdat bij **batch gradient descent** alle $m$ _observations_ worden gebruikt, is iedere gradient gebaseerd op de volledige _training set_.

### 5. Update de model parameters

De parameters worden aangepast in de tegengestelde richting van de gradient:

$\vec{\theta}_{\mathrm{next}}=\vec{\theta}-\eta\nabla_{\vec{\theta}}J(\vec{\theta})$

Hierbij is $\eta$ de _learning rate_.

De _gradient vector_ bevat voor iedere parameter de richting en grootte van de benodigde verandering. De _learning rate_ bepaalt vervolgens hoe groot de daadwerkelijke stap in die richting wordt.

Je trekt dus van iedere parameter de learning rate maal zijn partiële afgeleide af.

### 6. Herhaal

Het trainingsproces wordt iteratief herhaald:

```
initialiseer θ
    ↓
bereken predictions voor volledige training set
    ↓
bereken MSE
    ↓
bereken gradient over volledige training set
    ↓
update θ
    ↓
herhaal
```

Bij batch gradient descent wordt per [[5. Epoch#Epoch|epoch]] de volledige _training set_ verwerkt en vindt vervolgens één parameterupdate plaats.

Door dit proces te herhalen, worden de _model parameters_ aangepast in de richting waarin de MSE afneemt.
