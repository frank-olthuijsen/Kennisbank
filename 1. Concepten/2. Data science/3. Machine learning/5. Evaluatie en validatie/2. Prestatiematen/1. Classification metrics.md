- **Accuracy**: a performance measure often used in classification tasks
	- E.g., e-mails correctly classified as spam (by detecting unusually frequent patterns of words). 

## Slide: Case 5

### Recall versus Accuracy bij class imbalance

Stel dat een dataset met 1.000.000 huidafbeeldingen bestaat uit:

- 950.000 afbeeldingen van gezonde huid
- 50.000 afbeeldingen met een tumor

Een model dat **altijd voorspelt dat de huid gezond is**, heeft dan alsnog een hoge **Accuracy**:

$\text{Accuracy}=\frac{950.000}{1.000.000}=0{,}95$

Dus:

- **Accuracy = 95%**
- Geen enkele tumor wordt gedetecteerd

In dit geval is **Recall** voor de klasse `tumor` een veel nuttigere performance measure.

$\text{Recall}=\frac{TP}{TP+FN}$

Waarbij:

- $TP$ = **True Positives**: tumoren die correct als tumor worden herkend
- $FN$ = **False Negatives**: tumoren die ten onrechte als gezond worden geclassificeerd

Als geen enkele tumor wordt gevonden:

$\text{Recall}=\frac{0}{0+50.000}=0$

Dus:

- **Accuracy = 95%**
- **Recall = 0%**

> [!info] Class imbalance
> Bij een dataset met een sterke **class imbalance** kan **Accuracy** misleidend zijn. Een model kan een hoge Accuracy behalen door vooral de grootste klasse correct te voorspellen, terwijl het vrijwel alle voorbeelden uit de kleinere klasse mist.

In dit voorbeeld is **Recall**, in een medische context ook vaak **Sensitivity** genoemd, belangrijker omdat je vooral wilt voorkomen dat een patiënt **wel een tumor heeft, maar het model deze mist**.

> [!warning]
> Alleen Recall gebruiken is ook niet voldoende. Een model dat **iedere afbeelding als tumor classificeert** heeft een Recall van $100\%$, maar veroorzaakt enorm veel **False Positives**. Daarom worden doorgaans meerdere performance measures samen bekeken, bijvoorbeeld **Recall** en **Precision**.
