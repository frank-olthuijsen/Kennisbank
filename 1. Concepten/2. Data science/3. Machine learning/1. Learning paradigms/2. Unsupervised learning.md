## Unsupervised learning

> [!info] Unsupervised learning
> Een vorm van [[1. Machine learning|machine learning]] waarbij een model wordt getraind met data waarvoor geen **target** of **labels** bekend zijn.
> 
> Het model probeert zelfstandig structuur, patronen, verbanden of afwijkingen in de data te ontdekken, zonder dat vooraf is aangegeven wat de juiste uitkomst is.     

> [!example]+ Voorbeeld  
> Voorbeelden van unsupervised learning zijn:
> 
> - [[1. Clustering#Clustering|Clustering]]: bezoekers van een website automatisch indelen in groepen met vergelijkbaar gedrag.     
> - [[2. Hierarchical clustering#Hierarchical clustering|Hierarchical clustering]]: gevonden groepen verder onderverdelen in kleinere groepen.     
> - **Visualization**: complexe data terugbrengen tot een twee- of driedimensionale representatie zodat patronen zichtbaar worden.     
> - [[Kennisbank/1. Concepten/2. Data science/3. Machine learning/3. Tasks/4. Dimensionality reduction/0. Basisbegrippen/1. Dimensionality reduction#Dimensionality reduction|Dimensionality reduction]]: meerdere sterk gecorreleerde features samenvoegen tot een kleiner aantal nieuwe features, bijvoorbeeld met **feature extraction**.     
> - [[1. Anomaly detection#Anomaly detection|Anomaly detection]]: ongebruikelijke creditcardtransacties opsporen.     
> - [[1. Anomaly detection#Novelty detection|Novelty detection]]: nieuwe waarnemingen herkennen die sterk afwijken van de normale trainingsdata. Hierbij bestaat de trainingsdata alleen uit normale waarnemingen, terwijl de trainingsdata bij anomaly detection ook afwijkingen kan bevatten.     
> - [[1. Association rule learning#Association rule learning|Association rule learning]]: ontdekken dat klanten die product A en B kopen, vaak ook product C kopen.
