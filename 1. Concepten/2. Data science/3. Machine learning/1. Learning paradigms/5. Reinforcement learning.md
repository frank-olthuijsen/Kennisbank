## Reinforcement learning

> [!info] Reinforcement learning  
> Een vorm van [[1. Machine learning|machine learning]] waarbij een lerend systeem, de **agent**, door interactie met een **environment** leert welke **actions** het het beste kan uitvoeren.
> 
> De agent observeert de environment, kiest een action en ontvangt daarvoor een **reward** of **penalty**. Op basis van deze feedback leert de agent welke acties op langere termijn de meeste totale reward opleveren.
> 
> De strategie die bepaalt welke action de agent in een bepaalde situatie kiest, wordt de **policy** genoemd.

> [!example]+ Voorbeeld  
> Een robot leert zelfstandig door een ruimte te navigeren.
> 
> - De **agent** is de robot.
>     
> - De **environment** is de ruimte waarin de robot zich bevindt.
>     
> - Mogelijke **actions** zijn bijvoorbeeld vooruit bewegen, draaien of stoppen.
>     
> - De robot krijgt een **reward** wanneer hij dichter bij zijn doel komt en een **penalty** wanneer hij bijvoorbeeld tegen een obstakel botst.
>     
> 
> Door dit vaak te herhalen leert de robot een **policy** waarmee hij uiteindelijk zo efficiënt mogelijk zijn doel bereikt.
