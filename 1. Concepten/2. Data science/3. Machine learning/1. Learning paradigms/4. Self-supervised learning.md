> [!info] Self-supervised learning  
> Een vorm van [[1. Machine learning|machine learning]] waarbij de **targets** automatisch uit de trainingsdata zelf worden afgeleid, waardoor geen handmatig gelabelde data nodig zijn.
> 
> Hiervoor wordt bijvoorbeeld een deel van een waarneming verborgen en krijgt het model als taak om dit ontbrekende deel te voorspellen op basis van de overgebleven informatie.
> 
> Self-supervised learning wordt vaak gebruikt om een model eerst algemene patronen en representaties uit grote hoeveelheden ongelabelde data te laten leren. Het geleerde model kan daarna bijvoorbeeld met **transfer learning** worden gebruikt voor een specifieke taak.

> [!example]+ Voorbeeld  
> Een deel van een afbeelding of zin wordt gemaskeerd. Het model krijgt het niet-gemaskeerde deel als input en probeert het ontbrekende deel te voorspellen.
> 
> Bijvoorbeeld:
> 
> - bij een afbeelding wordt een gedeelte verborgen en probeert het model de ontbrekende beeldinformatie te reconstrueren;
>     
> - bij een zin worden één of meer woorden verborgen en probeert het model deze woorden uit de context te voorspellen.
>     
> 
> Een model kan op deze manier ook leren om afbeeldingen van verschillende diersoorten te reconstrueren en daarmee algemene kenmerken van dieren leren herkennen.
> 
> Met **transfer learning** kan dit vooraf getrainde model vervolgens verder worden getraind met een kleinere dataset waarin afbeeldingen wél van labels met de betreffende diersoort zijn voorzien. Het model kan zo leren om de afgebeelde diersoort te classificeren.
