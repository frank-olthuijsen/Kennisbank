## Model complexity

> [!info] Model complexity  
> **Model complexity** geeft aan hoe flexibel een model is en in welke mate het complexe patronen kan leren.
> 
> Een model met een hoge model complexity kan meer en ingewikkeldere verbanden in de data beschrijven, maar loopt daardoor ook meer risico op [[1. Overfitting en underfitting#Overfitting|overfitting]].
> 
> Een model met een lage model complexity is minder flexibel en loopt eerder risico op [[1. Overfitting en underfitting#Underfitting|underfitting]].
> 
> Model complexity wordt onder andere beïnvloed door de structuur van het model en de gekozen [[2. Parameters en hyperparameters#Hyperparameters|hyperparameters]].

> [!example]+ Voorbeeld  
> Een ziekenhuis wil op basis van patiëntkenmerken de opnameduur voorspellen.
> 
> Een eenvoudig linear regression model kan alleen relatief eenvoudige verbanden leren en heeft daarom een beperkte model complexity.
> 
> Een neural network met meerdere lagen en veel neuronen kan veel complexere verbanden leren en heeft daardoor een hogere model complexity.
### Relatie tussen model complexity en hoeveelheid data

De benodigde [[#Model complexity|model complexity]] hangt samen met de **hoeveelheid en kwaliteit van de beschikbare training data**:

| Situatie                                              | Gevolg                                                                                                        |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Model te eenvoudig voor het onderliggende patroon     | [[2. Bias en variance#Bias\|High bias]] → [[1. Overfitting en underfitting#Underfitting\|underfitting]]       |
| Passende model complexity                             | Algemene patronen worden geleerd → goede generalization                                                       |
| Model te complex ten opzichte van de beschikbare data | [[2. Bias en variance#Variance\|High variance]] → [[1. Overfitting en underfitting#Overfitting\|overfitting]] |

Een complex model heeft doorgaans **meer training data nodig** om goed te kunnen generaliseren. Met weinig data kan het model zich te sterk aanpassen aan toevallige eigenschappen van afzonderlijke datapunten.

Meer **representatieve training data** kan daarom overfitting verminderen. Meer data is echter geen garantie: ook de kwaliteit van de data, de hoeveelheid [[2. Noise|noise]] en de gekozen model complexity blijven belangrijk.
