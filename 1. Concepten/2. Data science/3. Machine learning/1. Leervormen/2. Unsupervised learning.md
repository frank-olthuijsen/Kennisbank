- The training set doesn't include labels.
- Typical tasks:
	- **Clustering**: finds groups within the data.
		- E.g., groups of similar visitors of a website.
	- **Hierarchical clustering**: can subdivide groups into smaller ones.
	- **Visualization**: output 2D or 3D representations of data.
	- **Dimensionality reduction**: simplifies data without losing too much information.
		- E.g., merging several correlated features into one (feature extraction).
	- **Anomaly detection**: finds data that differs from the data it was trained on.
		- E.g., unusual credit card transactions.
	- **Novelty detection**: aims to detect new instances that differ from all the training instances.
		- Similar to anomaly detection. However, its training set should contain **only normal observations**, whereas an anomaly-detection training set **may contain outliers** that the algorithm attempts to identify (and possibly flag).
	- **Association rule learning**: discovers relations between features.
		- E.g., if people buy product A and B then usually they also buy C.
