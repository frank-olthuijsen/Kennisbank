## ROC curve versus PR curve

De [[6. ROC curve|ROC curve]] en [[5. Precision-recall curve|precision-recall curve (PR curve)]] beoordelen beide de prestaties van een _binary classifier_ over verschillende [[1. Classification#Decision threshold|decision thresholds]], maar leggen de nadruk op verschillende aspecten van de prestaties.

||ROC curve|PR curve|
|---|---|---|
|**x-as**|_False positive rate (FPR)_| [[3. Precision, recall en specificity#Recall]] |
|**y-as**|_True positive rate (TPR)_, gelijk aan _recall_|[[3. Precision, recall en specificity#Precision]]|
|**Focus**|Onderscheid tussen _positive_ en _negative class_|Prestaties voor de _positive class_|
|**Bij class imbalance**|Kan een gunstig beeld geven wanneer de _negative class_ zeer groot is|Vaak informatiever wanneer de _positive class_ zeldzaam is|

Het belangrijkste verschil ontstaat bij [[9. Class imbalance|class imbalance]].

De _false positive rate_ van de ROC curve wordt berekend als:

$\text{FPR}=\frac{FP}{FP+TN}$

Wanneer de _negative class_ zeer groot is, kan het aantal _true negatives_ groot zijn. Daardoor kan de FPR laag blijven, zelfs als het absolute aantal _false positives_ aanzienlijk is.

_Precision_ kijkt daarentegen naar:

$\text{Precision}=\frac{TP}{TP+FP}$

Hier hebben _false positives_ direct invloed op de uitkomst. Daardoor laat een PR curve bij een zeldzame _positive class_ vaak duidelijker zien in hoeverre een hoge _recall_ gepaard gaat met veel _false positives_.

> [!example]+ Voorbeeld  
> Stel dat een dataset bestaat uit 10.000 patiënten, waarvan slechts 100 daadwerkelijk een bepaalde aandoening hebben.
> 
> Een model vindt veel van deze patiënten, maar classificeert tegelijkertijd honderden gezonde patiënten ten onrechte als positief.
> 
> Omdat er 9.900 werkelijk negatieve patiënten zijn, kan de _false positive rate_ relatief laag blijven. De ROC curve kan daardoor nog behoorlijk gunstig lijken.
> 
> Bij de PR curve verlagen deze _false positives_ direct de _precision_. De PR curve maakt daardoor duidelijker zichtbaar hoeveel van de positieve voorspellingen daadwerkelijk correct zijn.
> 
> Bij een sterk ongelijke verdeling waarbij vooral de prestaties voor de zeldzame _positive class_ belangrijk zijn, is de PR curve daarom vaak informatiever.
