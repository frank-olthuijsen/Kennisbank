## Prediction error

> [!info] Prediction error
> Een **prediction error** is het verschil tussen de door een model voorspelde waarde en de werkelijke [[2. Feature, label en target#Target|target]] voor **één** [[1. Dataset en observation#Observation|observation]].
>
> Voor observation $i$ kan de prediction error worden geschreven als:
>
> $e^{(i)}=h(x^{(i)})-y^{(i)}$
>
> Hierbij is:
> - $x^{(i)}$ de input van observation $i$;
> - $h(x^{(i)})$ de door het model voorspelde waarde;
> - $y^{(i)}$ de werkelijke targetwaarde.
>
> De prediction error geeft dus aan **hoe ver een afzonderlijke voorspelling van de werkelijke waarde afligt**. Metrics zoals RMSE en MAE combineren de prediction errors van meerdere observations tot één maat voor de modelprestatie.
>
> Het teken van de error geeft de richting van de afwijking aan. Soms wordt de formule omgekeerd geschreven als $y^{(i)}-h(x^{(i)})$. Voor RMSE en MAE maakt dit geen verschil, omdat de error daar respectievelijk wordt gekwadrateerd of absoluut genomen.

> [!example]+ Voorbeeld
> Een model voorspelt dat een patiënt $7$ dagen opgenomen zal zijn, terwijl de werkelijke opnameduur $5$ dagen is.
>
> De prediction error is:
>
> $7-5=2$
>
> Het model voorspelt de opnameduur dus $2$ dagen te hoog.
## Root Mean Squared Error (RMSE)

> [!info] Root Mean Squared Error (RMSE)
> **RMSE** is een functie voor regression die de grootte van de prediction errors over meerdere observations samenvat, waarbij grotere prediction errors relatief zwaar meetellen.
>
> Voor een dataset met feature matrix $X$, target vector $y$, $m$ observations en een model $h$ wordt RMSE berekend als:
>
> $RMSE(X,y,h)=\sqrt{\frac{1}{m}\sum_{i=1}^{m}(h(x^{(i)})-y^{(i)})^2}$
>
> Hierbij is:
> - $X$ de feature matrix met de feature values van alle observations;
> - $x^{(i)}$ de feature vector van observation $i$;
> - $y$ de target vector met de target values van alle observations;
> - $y^{(i)}$ de target value van observation $i$;
> - $h$ het model;
> - $h(x^{(i)})$ de voorspelde target value voor observation $i$;
> - $h(x^{(i)})-y^{(i)}$ de prediction error van observation $i$;
> - $m$ het aantal observations.
>
> De prediction errors worden eerst gekwadrateerd, waarna het gemiddelde wordt berekend en daarvan de vierkantswortel wordt genomen.
>
> Door het kwadrateren wegen grote prediction errors **relatief zwaar** mee. RMSE is daardoor gevoeliger voor grote prediction errors en outliers dan MAE.
>
> RMSE heeft dezelfde eenheid als de target value.
> 
> RMSE kan afhankelijk van het gebruik fungeren als [[6. Loss function#Relatie met performance metrics|cost function of performance metric]].
## Mean Absolute Error (MAE)

> [!info] Mean Absolute Error (MAE)
> **MAE** is een performance metric voor regression die de gemiddelde absolute grootte van de prediction errors over meerdere observations meet.
>
> Voor een dataset met feature matrix $X$, target vector $y$, $m$ observations en een model $h$ wordt MAE berekend als:
>
> $MAE(X,y,h)=\frac{1}{m}\sum_{i=1}^{m}|h(x^{(i)})-y^{(i)}|$
>
> Hierbij is:
> - $X$ de feature matrix met de feature values van alle observations;
> - $x^{(i)}$ de feature vector van observation $i$;
> - $y$ de target vector met de target values van alle observations;
> - $y^{(i)}$ de target value van observation $i$;
> - $h$ het model;
> - $h(x^{(i)})$ de voorspelde target value voor observation $i$;
> - $h(x^{(i)})-y^{(i)}$ de prediction error van observation $i$;
> - $m$ het aantal observations.
>
> Van iedere prediction error wordt de absolute waarde genomen. Deze absolute prediction errors worden vervolgens gemiddeld.
>
> Omdat de prediction errors niet worden gekwadrateerd, neemt hun bijdrage lineair toe met hun grootte. Grote prediction errors hebben daardoor **minder invloed** op MAE dan op RMSE.
>
> MAE heeft dezelfde eenheid als de target value.
## RMSE versus MAE

> [!example]  Voorbeeld
> Stel:
> 
> - prediction error $=2$
>     
>     - bij MAE telt deze mee als $2$
>     - bij RMSE wordt eerst $2^2=4$ berekend
>     <br>
> - prediction error $=10$
>     
>     - bij MAE telt deze mee als $10$
>     - bij RMSE wordt eerst $10^2=100$ berekend        
> 
> Een fout die $5$ keer zo groot is, levert bij het kwadrateren een waarde op die $25$ keer zo groot is.
## Relatie met vector norms

Bij regression kunnen de werkelijke target values worden weergegeven als de vector $y$ en de predicted target values als de vector $\hat{y}$.

Het verschil tussen beide vormt de **prediction error vector**:

$\hat{y}-y$

De grootte van deze vector kan worden gemeten met verschillende [[5. Normen en afstand#Norm (norm)|norms]].

[[2. Regression metrics#Mean Absolute Error (MAE)|MAE]] is gebaseerd op de $\ell_1$-norm van de prediction error vector:

$MAE=\frac{1}{m}\|\hat{y}-y\|_1$

[[2. Regression metrics#Root Mean Squared Error (RMSE)|RMSE]] is gebaseerd op de $\ell_2$-norm van de prediction error vector:

$RMSE=\frac{1}{\sqrt{m}}\|\hat{y}-y\|_2$

Omdat de $\ell_2$-norm grote componenten relatief zwaarder laat meewegen dan de $\ell_1$-norm, heeft RMSE meer nadruk op grote prediction errors en is RMSE gevoeliger voor outliers dan MAE.

Hoe hoger de normindex $p$, hoe zwaarder grote componenten relatief meewegen en hoe minder invloed kleine componenten relatief hebben.
