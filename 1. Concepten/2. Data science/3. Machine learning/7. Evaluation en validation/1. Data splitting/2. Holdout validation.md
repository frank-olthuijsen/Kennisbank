> [!info] Holdout validation  
> **Holdout validation** is een validatiemethode waarbij een deel van de beschikbare trainingsdata **apart wordt gehouden als validation set**.
> 
> Het model wordt getraind op de overgebleven training set en vervolgens beoordeeld op deze validation set. De validation set kan worden gebruikt om bijvoorbeeld verschillende modellen of [[2. Parameters en hyperparameters#Hyperparameters|hyperparameters]] met elkaar te vergelijken.
> 
> Bij holdout validation wordt hiervoor **één vaste splitsing** gebruikt. Dit verschilt van [[3. Cross-validation|cross-validation]], waarbij meerdere verschillende train/validation-splits worden gebruikt.
> 
> De test set blijft buiten dit proces en wordt pas gebruikt voor de uiteindelijke evaluatie van het gekozen model.
>
> Engels ook; **validation set**, **development set**, **dev set**

> [!example]+ Voorbeeld  
> Een ziekenhuis heeft gegevens van **10.000 patiënten** beschikbaar.
> 
> 1. Eerst worden **2.000 patiëntrecords** apart gehouden als [[1. Training, validation en test set#Test set|test set]]. Deze data wordt tijdens de ontwikkeling van het model niet gebruikt.
>     
> 2. De overige **8.000 records** vormen de [[1. Training, validation en test set#Training set|training set]]. Voor holdout validation wordt hiervan bijvoorbeeld:
>     
>     - **6.400 records** gebruikt om modellen te trainen;
>         
>     - **1.600 records** apart gehouden als [[1. Training, validation en test set#Validation set|validation set]].
>         
> 3. Verschillende modellen of modelconfiguraties met verschillende [[2. Parameters en hyperparameters#Hyperparameters|hyperparameters]] worden op de 6.400 records getraind en met de validation set beoordeeld.
>     
> 4. De best presterende modelconfiguratie wordt gekozen en vervolgens opnieuw getraind op de **volledige training set van 8.000 records**.
>     
> 5. Ten slotte wordt dit model beoordeeld op de **2.000 records uit de test set** om de [[1. Training, validation en test set#Training error en generalization error|generalization error]] te schatten.
