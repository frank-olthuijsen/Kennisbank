## Training set

> [!info] Training set  
> De **training set** is het deel van een dataset dat wordt gebruikt om een model te [[1. Training|trainen]].
> 
> Tijdens training leert het model zijn [[2. Parameters en hyperparameters#Parameters|parameters]] uit deze data.
## Exploration set

> [!info] Exploration set
> Een **exploration set** is een deel van de [[1. Training, validation en test set#Training set|training set]] dat wordt gebruikt om data te verkennen en analyseren tijdens *exploratory data analysis (EDA)*.
>
> Bij grote datasets kan een kleinere *exploration set* worden geselecteerd om analyses en visualisaties sneller uit te voeren.
>
> De exploration set wordt bijvoorbeeld gebruikt om:
> - de verdeling van *features* te onderzoeken;
> - ontbrekende waarden en outliers te identificeren;
> - verbanden tussen *features* te ontdekken.
>
> Een exploration set is geen verplichte afzonderlijke dataset. Bij kleinere datasets kan de volledige training set worden gebruikt voor data exploration.
>
> De [[1. Training, validation en test set#Test set|test set]] blijft buiten de data exploration om te voorkomen dat informatie uit de testdata de modelontwikkeling beïnvloedt.

> [!example]+ Voorbeeld
> Een ziekenhuis beschikt over een dataset met $100.000$ patiënten.
>
> Na het apart zetten van $20.000$ patiënten als test set blijven $80.000$ patiënten over als training set.
>
> Hieruit worden willekeurig $10.000$ patiënten geselecteerd als exploration set.
>
> Deze kleinere dataset wordt gebruikt om bijvoorbeeld leeftijdsverdelingen, ontbrekende waarden en correlaties te onderzoeken.
>
> Voor het uiteindelijke trainen van het model kunnen alle $80.000$ patiënten uit de training set worden gebruikt.
## Validation set

> [!info] Validation set  
> De **validation set** is het deel van een dataset dat tijdens de ontwikkeling van een model wordt gebruikt om keuzes over het model te beoordelen.
> 
> De validation set kan bijvoorbeeld worden gebruikt voor:
> 
> - het vergelijken van verschillende modellen;
>     
> - het kiezen van [[2. Parameters en hyperparameters#Hyperparameters|hyperparameters]];
>     
> - het bepalen van de juiste [[3. Model complexity en dataset size#Model complexity|model complexity]].
>     
> 
> De validation set wordt **niet gebruikt om de parameters van het model te trainen**.
## Test set

> [!info] Test set  
> De **test set** is het deel van een dataset dat pas na training en modelselectie wordt gebruikt om te beoordelen hoe goed het uiteindelijke model generaliseert naar nieuwe, onbekende data.
> 
> De test set mag daarom niet worden gebruikt voor het kiezen van een model of het afstellen van hyperparameters. Anders beïnvloedt de testdata indirect het model en geeft de uiteindelijke evaluatie een te optimistisch beeld.
## Out-of-sample data

> [!info] Out-of-sample data
> **Out-of-sample data** zijn data die niet zijn gebruikt om de [[1. Training, validation en test set#Training set|training set]] van een model te vormen en waarop het model dus niet is getraind.
>
> Deze data worden gebruikt om te beoordelen hoe goed een model [[0. Generalization|generaliseert]] naar nieuwe, onbekende data.
> 
> De [[1. Training, validation en test set#Validation set|validation set]] en [[1. Training, validation en test set#Test set|test set]] bestaan uit *out-of-sample data* ten opzichte van het model dat op de *training set* is getraind.
## Data snooping bias

> [!info] Data snooping bias
> **Data snooping bias** is de bias die ontstaat wanneer informatie uit de [[1. Training, validation en test set#Test set|test set]] tijdens model development wordt gebruikt of modelkeuzes beïnvloedt.
>
> Dit kan niet alleen gebeuren door performance op de test set te gebruiken voor model selection of tuning, maar ook door de test data inhoudelijk te inspecteren en op basis daarvan keuzes te maken.
>
> De test set is dan niet langer volledig onafhankelijk van het ontwikkelproces. De gemeten test performance kan daardoor een te optimistische schatting van de [[1. Training, validation en test set#Training error en generalization error|generalization error]] geven.
>
> De test set wordt daarom idealiter pas gebruikt nadat training, preprocessing, feature engineering, model selection en tuning zijn afgerond.
## Relatie tussen de datasets

|Dataset|Doel|
|---|---|
|**Training set**|Parameters van het model leren|
|**Validation set**|Model en hyperparameters kiezen|
|**Test set**|Uiteindelijke prestaties op onbekende data schatten|

De precieze verdeling van de beschikbare data over deze datasets hangt af van onder andere de hoeveelheid beschikbare data. Er bestaat dus geen vaste verdeling die altijd moet worden gebruikt.

Bij [[3. Cross-validation|cross-validation]] kan de validation set worden vervangen door meerdere tijdelijke train/validation-splits van de trainingsdata. De test set blijft daarbij apart staan.
## Training error en generalization error

> [!info] Training error  
> De **training error** is de fout die een model maakt op de training set.

> [!info] Generalization error  
> De **generalization error** is de verwachte fout van een model op nieuwe, onbekende data.
> 
> Omdat deze fout niet rechtstreeks voor alle toekomstige data kan worden bepaald, wordt hij in de praktijk **geschat met de test set**.
> 
> Engels ook: **out-of-sample error**

Een lage training error gecombineerd met een duidelijk hogere fout op validation- of testdata kan wijzen op [[1. Overfitting en underfitting#Overfitting|overfitting]].
