## Precision-recall curve

> [!info] Precision-recall curve (PR curve)  
> Een **precision-recall curve (PR curve)** is een grafiek die laat zien hoe [[3. Precision, recall en specificity#Precision|precision]] en [[3. Precision, recall en specificity#Recall|recall]] van een _binary classifier_ veranderen bij verschillende [[4. Decision threshold#Decision threshold|decision thresholds]].
> 
> Voor iedere _decision threshold_ wordt een punt bepaald met:
> 
> - op de x-as de _recall_;
>     
> - op de y-as de _precision_.
>     
> 
> Door de _decision threshold_ te variëren ontstaan verschillende combinaties van _precision_ en _recall_. Deze punten vormen samen de PR curve.
> 
> Een lagere _decision threshold_ leidt doorgaans tot meer positieve _predictions_. Hierdoor neemt _recall_ meestal toe, terwijl _precision_ kan afnemen doordat ook meer _false positives_ ontstaan.
> 
> Een goede _classifier_ bereikt bij voorkeur zowel een hoge _precision_ als een hoge _recall_. De PR curve ligt dan zo veel mogelijk richting de rechterbovenhoek.
> 
> De PR curve is vooral nuttig bij [[10. Class imbalance|class imbalance]], omdat zij specifiek laat zien hoe goed het model de _positive class_ herkent zonder daarbij te veel _false positives_ te produceren.

> [!example]+ Voorbeeld  
> Een model voorspelt of een patiënt een tumor heeft.
> 
> Bij een hoge _decision threshold_ worden alleen patiënten met een hoge score als positief geclassificeerd. Hierdoor kan de _precision_ hoog zijn, maar worden mogelijk tumoren gemist en is de _recall_ lager.
> 
> Wanneer de _decision threshold_ wordt verlaagd, worden meer patiënten als positief geclassificeerd. Hierdoor worden doorgaans meer werkelijke tumoren gevonden en stijgt de _recall_, maar kunnen ook meer patiënten zonder tumor ten onrechte positief worden geclassificeerd, waardoor de _precision_ kan dalen.
> 
> De PR curve toont deze afweging voor verschillende mogelijke _decision thresholds_.
