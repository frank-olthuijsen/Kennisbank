## Confusion matrix

> [!info] Confusion matrix  
> Een **confusion matrix** is een matrix die voor een [[1. Classification#Classification|classification]]-model weergeeft hoe vaak iedere werkelijke _class_ als iedere mogelijke _class_ is voorspeld.
> 
> De rijen vertegenwoordigen de werkelijke _classes_ en de kolommen de voorspelde _classes_. Waarden op de hoofddiagonaal zijn correcte voorspellingen; waarden buiten de hoofddiagonaal zijn verkeerde voorspellingen.
> 
> Een _confusion matrix_ is doorgaans **niet symmetrisch**. Dat een model _class_ $A$ bijvoorbeeld tien keer ten onrechte als $B$ voorspelt, betekent niet dat het $B$ ook tien keer als $A$ voorspelt. Deze twee soorten fouten staan op verschillende posities in de matrix en kunnen verschillende aantallen hebben.

Bij [[4. Classification types#Binary classification|binary classification]] kunnen de voorspellingen in vier groepen worden verdeeld:

|                        | Voorspeld negatief  | Voorspeld positief  |
| ---------------------- | ------------------- | ------------------- |
| **Werkelijk negatief** | True negative (TN)  | False positive (FP) |
| **Werkelijk positief** | False negative (FN) | True positive (TP)  |
*De gehanteerde indeling is die van de [confusion matrix van scikit-learn](https://scikit-learn.org/stable/modules/model_evaluation.html#confusion-matrix).*

De matrix is in dit geval alleen symmetrisch wanneer het aantal _false positives_ gelijk is aan het aantal _false negatives_.

Deze waarden vormen de basis voor verschillende _classification metrics_, zoals [[2. Accuracy#Accuracy|accuracy]], [[3. Precision, recall en specificity#Precision|precision]], [[3. Precision, recall en specificity#Recall|recall]] en [[3. Precision, recall en specificity#Specificity|specificity]].

> [!example]+ Voorbeeld  
> Stel dat een model bepaalt of een patiënt een aandoening heeft:
> 
> ||Voorspeld negatief|Voorspeld positief|
> |---|---|---|
> |**Werkelijk negatief**|80|10|
> |**Werkelijk positief**|5|25|
> 
> Er zijn hier `10` _false positives_, maar slechts `5` _false negatives_. De _confusion matrix_ is daarom niet symmetrisch.
