## Mean Absolute Error (MAE)

> [!info] Mean Absolute Error (MAE)
> **MAE** is een performance metric voor regression die de gemiddelde absolute grootte van de [[1. Prediction error#Prediction error|prediction errors]] over meerdere observations meet.
>
> Voor een dataset met feature matrix $X$, target vector $y$, $m$ observations en een model $h$ wordt MAE berekend als:
>
> $MAE(X,y,h)=\frac{1}{m}\sum_{i=1}^{m}|h(x^{(i)})-y^{(i)}|$
>
> Hierbij is:
> - $X$ de feature matrix met de feature values van alle observations;
> - $x^{(i)}$ de feature vector van observation $i$;
> - $y$ de target vector met de target values van alle observations;
> - $y^{(i)}$ de target value van observation $i$;
> - $h$ het model;
> - $h(x^{(i)})$ de voorspelde target value voor observation $i$;
> - $h(x^{(i)})-y^{(i)}$ de prediction error van observation $i$;
> - $m$ het aantal observations.
>
> Van iedere prediction error wordt de absolute waarde genomen. Deze absolute prediction errors worden vervolgens gemiddeld.
>
> Omdat de prediction errors niet worden gekwadrateerd, neemt hun bijdrage lineair toe met hun grootte. Grote prediction errors hebben daardoor **minder invloed** op MAE dan op RMSE.
>
> MAE heeft dezelfde eenheid als de target value.
## Relatie tussen MAE en de $\ell_1$-norm

> [!info] Relatie tussen MAE en de $\ell_1$-norm
> De **Mean Absolute Error (MAE)** is gebaseerd op de [[5. Normen en afstand#$\ell_1$-norm|l1-norm]] van de vector met *prediction errors*, gedeeld door het aantal *observations*.
>
> De MAE wordt berekend als:
>
> $MAE=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|$
>
> Wanneer de *prediction errors* worden verzameld in een vector $e=(e_1,e_2,\ldots,e_n)$, geldt:
>
> $\|e\|_1=\sum_{i=1}^{n}|e_i|$
>
> Daarmee kan MAE worden geschreven als:
>
> $MAE=\frac{\|e\|_1}{n}$
>
> De deling door $n$ normaliseert de norm naar het aantal *observations*. Doordat de absolute waarden worden opgeteld zonder de fouten te kwadrateren, wegen grote fouten relatief minder zwaar mee dan bij RMSE.

> [!example]+ Voorbeeld
> Een model maakt bij drie *observations* de volgende *prediction errors*:
>
> $e=(1,2,3)$
>
> De $\ell_1$-norm bedraagt:
>
> $\|e\|_1=|1|+|2|+|3|=6$
>
> De MAE wordt:
>
> $MAE=\frac{6}{3}=2$
>
> De MAE is dus de $\ell_1$-norm van de foutvector, genormaliseerd met $n$.
