## Root Mean Squared Error (RMSE)

> [!info] Root Mean Squared Error (RMSE)
> **RMSE** is een functie voor regression die de grootte van de [[1. Prediction error#Prediction error|prediction errors]] over meerdere observations samenvat, waarbij grotere prediction errors relatief zwaar meetellen.
>
> Voor een dataset met feature matrix $X$, target vector $y$, $m$ observations en een model $h$ wordt RMSE berekend als:
>
> $RMSE(X,y,h)=\sqrt{\frac{1}{m}\sum_{i=1}^{m}(h(x^{(i)})-y^{(i)})^2}$
>
> Hierbij is:
> - $X$ de feature matrix met de feature values van alle observations;
> - $x^{(i)}$ de feature vector van observation $i$;
> - $y$ de target vector met de target values van alle observations;
> - $y^{(i)}$ de target value van observation $i$;
> - $h$ het model;
> - $h(x^{(i)})$ de voorspelde target value voor observation $i$;
> - $h(x^{(i)})-y^{(i)}$ de prediction error van observation $i$;
> - $m$ het aantal observations.
>
> De prediction errors worden eerst gekwadrateerd, waarna het gemiddelde wordt berekend en daarvan de vierkantswortel wordt genomen.
>
> Door het kwadrateren wegen grote prediction errors **relatief zwaar** mee. RMSE is daardoor gevoeliger voor grote prediction errors en outliers dan MAE.
> 
> RMSE is gebaseerd op de [[5. Normen en afstand#$\ell_2$-norm|$\ell_2$-norm]] van de vector met _prediction errors_, gedeeld door $\sqrt{n}$. Hierdoor wegen grote fouten relatief zwaarder mee dan bij MAE.
>
> RMSE heeft dezelfde eenheid als de target value.
> 
> RMSE kan afhankelijk van het gebruik fungeren als [[2. Cost function#Relatie met performance metrics|cost function of performance metric]].
## Relatie tussen RMSE en de $\ell_2$-norm

> [!info] Relatie tussen RMSE en de $\ell_2$-norm
> De **Root Mean Squared Error (RMSE)** is gebaseerd op de [[5. Normen en afstand#$\ell_2$-norm|l2-norm]] van de vector met *prediction errors*, gedeeld door de wortel van het aantal *observations*.
>
> De RMSE wordt berekend als:
>
> $RMSE=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}$
>
> Wanneer de *prediction errors* worden verzameld in een vector $e=(e_1,e_2,\ldots,e_n)$, geldt:
>
> $\|e\|_2=\sqrt{\sum_{i=1}^{n}e_i^2}$
>
> Daarmee kan RMSE worden geschreven als:
>
> $RMSE=\frac{\|e\|_2}{\sqrt{n}}$
>
> De deling door $\sqrt{n}$ normaliseert de norm naar het aantal *observations*. Doordat de fouten worden gekwadrateerd, wegen grote fouten relatief zwaarder mee.

> [!example]+ Voorbeeld
> Een model maakt bij drie *observations* de volgende *prediction errors*:
>
> $e=(1,2,3)$
>
> De $\ell_2$-norm bedraagt:
>
> $\|e\|_2=\sqrt{1^2+2^2+3^2}=\sqrt{14}$
>
> De RMSE wordt:
>
> $RMSE=\frac{\sqrt{14}}{\sqrt{3}}=\sqrt{\frac{14}{3}}\approx 2{,}16$
>
> De RMSE is dus de $\ell_2$-norm van de foutvector, genormaliseerd met $\sqrt{n}$.

## RMSE versus MSE

Omdat $RMSE=\sqrt{MSE}$ verandert de vierkantswortel alleen de **grootte van de waarden**, niet hun onderlinge volgorde. Een lagere MSE blijft dus ook een lagere RMSE.

Daarom bereiken MSE en RMSE hun minimum bij **dezelfde modelparameters**. Alleen de waarde van de maat verschilt; de plek van het minimum blijft hetzelfde.

## RMSE versus MAE

> [!example]  Voorbeeld
> Stel:
> 
> - prediction error $=2$
>     
>     - bij MAE telt deze mee als $2$
>     - bij RMSE wordt eerst $2^2=4$ berekend
>     <br>
> - prediction error $=10$
>     
>     - bij MAE telt deze mee als $10$
>     - bij RMSE wordt eerst $10^2=100$ berekend        
> 
> Een fout die $5$ keer zo groot is, levert bij het kwadrateren een waarde op die $25$ keer zo groot is.
