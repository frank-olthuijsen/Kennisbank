## Anomaly detection

> [!info] Anomaly detection  
> **Anomaly detection** is een machine-learningtask waarbij [[1. Dataset en observation#Observation|observations]] worden geïdentificeerd die sterk afwijken van het normale of verwachte patroon in de data.
> 
> Zulke afwijkende observations worden **anomalies** of **outliers** genoemd.
> 
> Anomaly detection wordt vaak toegepast als [[2. Unsupervised learning#Unsupervised learning|unsupervised learning]], waarbij vooraf geen labels beschikbaar zijn die aangeven welke observations afwijkend zijn.
> 
> Bij **anomaly detection** kan de _training data_ zowel normale als afwijkende observations bevatten. Dit verschilt van [[1. Anomaly detection#Novelty detection|novelty detection]], waarbij het model wordt getraind op data die als normaal wordt beschouwd en vervolgens wordt gebruikt om afwijkende nieuwe observations te herkennen.

> [!example]+ Voorbeeld  
> Een ziekenhuis verzamelt continu meetwaarden van medische apparatuur.
> 
> De meeste measurements volgen een vergelijkbaar patroon. Wanneer een combinatie van waarden sterk afwijkt van wat normaal voorkomt, kan een anomaly detection algorithm deze observation als een **anomaly** markeren voor nader onderzoek.
## Novelty detection

> [!info] Novelty detection  
> **Novelty detection** is een vorm van [[1. Anomaly detection#Anomaly detection|anomaly detection]] waarbij een model wordt getraind op _training data_ die uitsluitend of vrijwel uitsluitend normale [[1. Dataset en observation#Observation|observations]] bevat.
> 
> Het model leert daarmee wat als normaal wordt beschouwd en wordt vervolgens gebruikt om nieuwe observations te herkennen die sterk afwijken van dit normale patroon.
> 
> Het verschil met algemene _anomaly detection_ is dat de _training data_ bij novelty detection wordt verondersteld vrij te zijn van anomalies, terwijl anomaly detection ook kan worden toegepast op data waarin afwijkende observations al aanwezig zijn.

> [!example]+ Voorbeeld  
> Een model wordt getraind met meetgegevens van medische apparatuur tijdens normaal functioneren.
> 
> Nadat het model het normale patroon heeft geleerd, worden nieuwe metingen ermee beoordeeld. Een nieuwe observation die sterk afwijkt van het geleerde patroon kan als **novelty** worden aangemerkt en bijvoorbeeld wijzen op een mogelijke storing.
