## Class

> [!info] Class  
> Een **class** is een vooraf bepaalde categorie waaraan een [[1. Dataset en observation#Observation|observation]] bij [[1. Classification#Classification|classification]] kan worden toegewezen.
> 
> De mogelijke classes vormen samen de categorieën waaruit het model kan kiezen. Het [[2. Feature, label en target#Label|label]] geeft aan tot welke class een specifieke observation behoort.
## Positive class

> [!info] Positive class  
> De **positive class** is de [[#Class|class]] waarvan bij de evaluatie specifiek wordt bepaald of een _observation_ ertoe behoort.
> 
> Bij [[4. Classification types#Binary classification|binary classification]] is dit één van de twee classes en wordt deze vaak aangeduid met het label $1$. Bij _multiclass classification_ kan één class voor de evaluatie als _positive class_ worden beschouwd en worden de overige classes gezamenlijk als _negative class_ behandeld.

> [!example]+ Voorbeeld  
> Bij een model dat voorspelt of een patiënt een tumor heeft, kan `tumor aanwezig` de _positive class_ zijn:
> 
> - $1$ = tumor aanwezig;
>     
> - $0$ = geen tumor.
>     
## Negative class

> [!info] Negative class  
> De **negative class** bestaat uit de [[#Class|class]] of classes die bij de evaluatie niet als _positive class_ worden beschouwd.
> 
> Bij [[4. Classification types#Binary classification|binary classification]] is dit één van de twee classes en wordt deze vaak aangeduid met het label $0$. Bij _multiclass classification_ kunnen alle classes behalve de gekozen _positive class_ gezamenlijk als _negative class_ worden behandeld.

> [!example]+ Voorbeeld  
> Bij een model dat voorspelt of een patiënt een tumor heeft, kan `geen tumor` de _negative class_ zijn:
> 
> - $0$ = geen tumor;
>     
> - $1$ = tumor aanwezig.
