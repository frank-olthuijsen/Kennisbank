## Negative class

> [!info] Negative class  
> De **negative class** bestaat uit de [[1. Class#Class|class]] of classes die bij de evaluatie niet als _positive class_ worden beschouwd.
> 
> Bij [[1. Binary classification#Binary classification|binary classification]] is dit één van de twee classes en wordt deze vaak aangeduid met het label $0$. Bij _multiclass classification_ kunnen alle classes behalve de gekozen _positive class_ gezamenlijk als _negative class_ worden behandeld.

> [!example]+ Voorbeeld  
> Bij een model dat voorspelt of een patiënt een tumor heeft, kan `geen tumor` de _negative class_ zijn:
> 
> - $0$ = geen tumor;
>     
> - $1$ = tumor aanwezig.
