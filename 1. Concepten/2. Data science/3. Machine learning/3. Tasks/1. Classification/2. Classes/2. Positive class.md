## Positive class

> [!info] Positive class  
> De **positive class** is de [[1. Class#Class|class]] waarvan bij de evaluatie specifiek wordt bepaald of een _observation_ ertoe behoort.
> 
> Bij [[1. Binary classification#Binary classification|binary classification]] is dit één van de twee classes en wordt deze vaak aangeduid met het label $1$. Bij _multiclass classification_ kan één class voor de evaluatie als _positive class_ worden beschouwd en worden de overige classes gezamenlijk als _negative class_ behandeld.

> [!example]+ Voorbeeld  
> Bij een model dat voorspelt of een patiënt een tumor heeft, kan `tumor aanwezig` de _positive class_ zijn:
> 
> - $1$ = tumor aanwezig;
>     
> - $0$ = geen tumor.
>
