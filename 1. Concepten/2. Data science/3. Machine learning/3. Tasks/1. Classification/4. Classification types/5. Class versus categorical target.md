## Verschil tussen class en categorische target

Een **categorische target** is de uitkomstvariabele die een model probeert te voorspellen.

Een **class** is één van de mogelijke categorieën die deze target kan aannemen.

Bijvoorbeeld:

```
Target: kleur
Classes: rood, blauw, groen
```

De relatie is dus:

```
categorische target → mogelijke waarden = classes
```

Bij _multioutput classification_ zijn er meerdere categorische targets:

```
Target 1: carrosserietype
Classes: sedan, SUV, hatchback

Target 2: kleur
Classes: rood, blauw, zwart

Target 3: aandrijving
Classes: benzine, diesel, elektrisch
```

Een _class_ is dus geen afzonderlijke target, maar een **mogelijke waarde van een categorische target**.
