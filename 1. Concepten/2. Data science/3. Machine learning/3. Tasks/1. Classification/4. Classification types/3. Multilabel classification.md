## Multilabel classification

> [!info] Multilabel classification  
> **Multilabel classification** is [[1. Classification#Classification|classification]] waarbij één [[1. Dataset en observation#Observation|observation]] **nul, één of meerdere labels uit één gezamenlijke verzameling** kan krijgen.
> 
> Zie: [[5. Class versus categorical target#Verschil tussen class en categorische target|Verschil tussen class en categorische target]]
> 
> In tegenstelling tot [[2. Multiclass classification#Multiclass classification|multiclass classification]], waarbij iedere _observation_ precies één _class_ krijgt, kunnen bij _multilabel classification_ meerdere _classes_ tegelijkertijd van toepassing zijn, maar ook geen enkele.
> 
> [[4. Multioutput classification#Multioutput classification|Multioutput classification]] voorspelt daarentegen meerdere afzonderlijke categorische _targets_, waarbij iedere _target_ zijn eigen verzameling mogelijke _classes_ heeft.

> [!example]+ Voorbeeld  
> Een model analyseert een röntgenfoto en kan uit de verzameling `longontsteking`, `pleuravocht` en `fractuur` bepalen welke aandoeningen aanwezig zijn.
> 
> Een afbeelding kan bijvoorbeeld:
> 
> - geen van deze _labels_ krijgen
> - alleen `longontsteking` krijgen     
> - zowel `longontsteking` als `pleuravocht` krijgen     
> 
> Omdat nul, één of meerdere _labels_ uit dezelfde verzameling aan één _observation_ kunnen worden toegewezen, gaat het om _multilabel classification_.
