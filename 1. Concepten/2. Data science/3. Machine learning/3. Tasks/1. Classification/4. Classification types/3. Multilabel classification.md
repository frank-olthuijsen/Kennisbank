## Multilabel classification

> [!info] Multilabel classification  
> **Multilabel classification** is [[1. Classification#Classification|classification]] waarbij één [[1. Dataset en observation#Observation|observation]] tegelijkertijd aan **meerdere** [[1. Class#Class|classes]] kan worden toegewezen.
> 
> Zie: [[5. Class versus categorical target#Verschil tussen class en categorische target|Verschil tussen class en categorische target]]
> 
> In tegenstelling tot [[2. Multiclass classification#Multiclass classification|multiclass classification]], waarbij iedere _observation_ precies één _class_ krijgt, kunnen bij _multilabel classification_ meerdere _classes_ tegelijk van toepassing zijn. 

> [!example]+ Voorbeeld  
> Een model analyseert een röntgenfoto en kan verschillende aandoeningen herkennen. Eén afbeelding kan bijvoorbeeld tegelijkertijd de _labels_ `longontsteking` en `pleuravocht` krijgen.
> 
> Omdat meerdere _classes_ tegelijkertijd aan dezelfde _observation_ kunnen worden toegewezen, gaat het om _multilabel classification_.
