## Principal component analysis (PCA)

> [!info] Principal component analysis (PCA)
> **Principal component analysis (PCA)** is een lineaire methode voor [[Kennisbank/1. Concepten/2. Data science/3. Machine learning/3. Tasks/4. Dimensionality reduction/0. Basisbegrippen/1. Dimensionality reduction|dimensionality reduction]] waarbij de richtingen met de grootste [[2. Spreidingsmaten#Variantie|variantie]] in de data worden bepaald.
>
> Deze onderling orthogonale richtingen worden [[2. Principal component#Principal component|principal components]] genoemd en vormen de assen van een nieuwe *feature space*. Deze kunnen worden gevonden middels [[1. Singulierewaardenontbinding#Singulierewaardenontbinding|singular value decomposition (SVD)]].
>
> De principal components worden geordend op basis van de hoeveelheid variantie die ze verklaren, van groot naar klein.
>
> Door de data vervolgens te projecteren op een subset van de principal components met de grootste verklaarde variantie, kan het aantal dimensies worden verminderd terwijl zoveel mogelijk van de oorspronkelijke variantie behouden blijft.
>
> Deze transformatie wordt beschreven bij [[4. PCA transformation#PCA transformation|PCA transformation]].
>
> PCA is daarmee een vorm van zowel [[1. Projection#Projection|projection]] als [[1. Feature engineering#Feature extraction|feature extraction]].
>
> PCA kan ook worden toegepast zonder het aantal dimensies te verminderen, door alle principal components te behouden. Het doel is dan niet dimensionality reduction, maar het verkrijgen van een nieuwe representatie van de data waarin de features onderling ongecorreleerd zijn en geordend zijn op basis van hun verklaarde variantie.
