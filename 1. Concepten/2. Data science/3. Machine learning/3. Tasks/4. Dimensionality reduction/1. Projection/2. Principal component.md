## Principal component

> [!info] Principal component  
> Een **principal component** is een richting in de oorspronkelijke [[2. Feature, label en target#Feature space|feature space]] waarlangs de data zoveel mogelijk [[2. Spreidingsmaten#Variantie|variantie]] vertoont.
> 
> Bij [[3. Principal component analysis#Principal component analysis (PCA)|principal component analysis (PCA)]] worden meerdere principal components bepaald:
> 
> - de eerste principal component wijst in de richting met de grootste variantie;     
> - iedere volgende principal component verklaart zoveel mogelijk van de resterende variantie en staat loodrecht op de eerdere principal components.     
> 
> De principal components vormen daarmee nieuwe assen waarop de gecentreerde data kan worden geprojecteerd.
