## PCA transformation

> [!info] PCA transformation  
> Een **PCA transformation** transformeert een [[2. Feature, label en target#Feature vector|feature vector]] van de oorspronkelijke _feature space_ naar een nieuwe _feature space_ waarvan de assen de [[3. Principal component#Principal component|principal components]] zijn.
> 
> Eerst wordt het gemiddelde van iedere oorspronkelijke _feature_ afgetrokken. Vervolgens wordt de gecentreerde _feature vector_ geprojecteerd op de gekozen _principal components_:
> 
> $\mathbf{z}=W^{\mathrm T}(\mathbf{x}-\boldsymbol{\mu})$
> 
> waarbij:
> 
> - $\mathbf{x}$ = oorspronkelijke _feature vector_;     
> - $\boldsymbol{\mu}$ = vector met de gemiddelden van de oorspronkelijke _features_;     
> - $W$ = matrix waarvan de kolommen de gekozen _principal components_ zijn;     
> - $\mathbf{z}$ = getransformeerde _feature vector_ met de **principal component scores**.     
> 
> Wanneer minder _principal components_ worden behouden dan het aantal oorspronkelijke _features_, voert de PCA transformation [[Kennisbank/1. Concepten/2. Data science/3. Machine learning/3. Tasks/4. Dimensionality reduction/1. Dimensionality reduction#Dimensionality reduction|dimensionality reduction]] uit.

> [!example]+ Voorbeeld  
> Een dataset bevat $10$ oorspronkelijke _features_. PCA bepaalt $10$ principal components.
> 
> Wanneer alleen de eerste $3$ principal components worden behouden, transformeert de PCA transformation iedere oorspronkelijke feature vector met $10$ waarden naar een nieuwe feature vector met $3$ principal component scores.
> 
> De oorspronkelijke _features_ worden daarbij dus niet geselecteerd; ze worden gecombineerd tot nieuwe _features_. Daarmee is PCA een vorm van [[1. Feature engineering#Feature extraction|feature extraction]].
