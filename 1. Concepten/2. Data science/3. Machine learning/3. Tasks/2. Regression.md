## Regression

> [!info] Regression
> Een taak binnen [[1. Supervised learning|supervised learning]] waarbij een model leert om op basis van [[2. Feature, label en target#Feature|features]] een **numerieke waarde** te voorspellen.
> 
> Tijdens het trainen krijgt het model voorbeelden waarbij de juiste numerieke uitkomst, de [[2. Feature, label en target#Target|target]], bekend is. Het model probeert het verband tussen de features en deze target te leren.

> [!example]+ Voorbeeld  
> Een model wordt getraind om de **opnameduur van een patiënt in dagen** te voorspellen.
> 
> - **Features** kunnen bijvoorbeeld leeftijd, diagnose en eerdere opnames zijn.     
> - De **target** is het aantal dagen dat de patiënt uiteindelijk opgenomen was.     
> 
> Omdat de voorspelde uitkomst een numerieke waarde is, gaat het om **regression**.
### Simple regression

> [!info] Simple regression
> **Simple regression** is een [[2. Regression|regression]]-probleem waarbij **één** [[2. Feature, label en target#Feature|feature]] wordt gebruikt om **één** numerieke [[2. Feature, label en target#Target|target]] te voorspellen.
> 
> Wanneer hiervoor een lineair model wordt gebruikt, spreken we specifieker van **simple linear regression**.

> [!example]+ Voorbeeld  
> Een model gebruikt alleen de **leeftijd** van een patiënt om de **opnameduur** te voorspellen.
> 
> - Leeftijd is de enige **feature**.     
> - Opnameduur is de enige **target**.     
> 
> Omdat één feature wordt gebruikt om één numerieke target te voorspellen, gaat het om **simple regression**.
### Multiple regression
> [!info] Multiple regression
> Een **multiple regression problem** is een [[2. Regression|regression]]-probleem waarbij **twee of meer** [[2. Feature, label en target#Feature|features]] worden gebruikt om **één** numerieke [[2. Feature, label en target#Target|target]] te voorspellen.
> 
> Het onderscheid met een eenvoudig regression problem met één feature zit dus in het **aantal inputvariabelen**, niet in het aantal targets.

> [!example]+ Voorbeeld  
> Een model voorspelt de opnameduur van een patiënt op basis van:
> 
> - leeftijd     
> - BMI     
> - aantal eerdere opnames>     
> 
> De drie waarden zijn **features** en de opnameduur is de **target**. Omdat meerdere features worden gebruikt om één numerieke target te voorspellen, is dit een **multiple regression problem**.
### Univariate regression

> [!info] Univariate regression
> **Univariate regression** is een [[2. Regression|regression]]-probleem waarbij **één** numerieke [[2. Feature, label en target#Target|target]] wordt voorspeld.
> 
> Het aantal [[2. Feature, label en target#Feature|features]] kan daarbij één of meer zijn. **Univariate** verwijst hier naar het aantal targets, niet naar het aantal features.

> [!example]+ Voorbeeld  
> Een model voorspelt de **opnameduur** van een patiënt op basis van leeftijd, BMI en het aantal eerdere opnames.
> 
> Er worden meerdere features gebruikt, maar slechts één target voorspeld: de opnameduur. Daarmee is dit een **univariate regression**-probleem.

### Multivariate regression
> [!info] Multivariate regression
> **Multivariate regression** is een [[2. Regression|regression]]-probleem waarbij een model **twee of meer** numerieke [[2. Feature, label en target#Target|targets]] tegelijk voorspelt.
> 
> Het model kan daarbij één of meer [[2. Feature, label en target#Feature|features]] als input gebruiken.
> 
> Dit verschilt van **multiple regression**, waarbij meerdere features worden gebruikt om één target te voorspellen.

> [!example]+ Voorbeeld  
> Een model gebruikt leeftijd, BMI en bloeddruk van een patiënt om tegelijkertijd te voorspellen:
> 
> - de verwachte opnameduur     
> - de verwachte zorgkosten.     
> 
> Er zijn meerdere features én twee numerieke targets. Omdat meerdere targets tegelijk worden voorspeld, gaat het om **multivariate regression**.
