## Feature mapping

> [!info] Feature mapping  
> Een **feature mapping** is een functie die een oorspronkelijke input omzet naar een nieuwe [[2. Feature, label en target#Feature vector|feature vector]] in een andere [[2. Feature, label en target#Feature space|feature space]].
> 
> Bij meerdere oorspronkelijke features wordt de input doorgaans als feature vector $\mathbf{x}$ geschreven:
> 
> $\boldsymbol{\phi}(\mathbf{x})=\begin{pmatrix}\\ \phi_1(\mathbf{x})\\ \phi_2(\mathbf{x})\\ \vdots\\ \phi_M(\mathbf{x})\end{pmatrix}$
> 
> Iedere component $\phi_j$ berekent één nieuwe feature uit de oorspronkelijke input.
> 
> Wanneer de functies $\phi_j$ samen een functionele basis vormen, worden ze [[6. Basisfunctie#Basisfunctie|basisfuncties]] genoemd. De feature mapping verzamelt dan de uitkomsten van deze basisfuncties in één nieuwe feature vector.
> 
> Bij slechts één oorspronkelijke feature is de input een scalair $x$ in plaats van een vector $\mathbf{x}$. De feature mapping wordt dan bijvoorbeeld geschreven als:
> 
> $\boldsymbol{\phi}(x)=\begin{pmatrix}\\ \phi_0(x)\\ \phi_1(x)\\ \vdots\\ \phi_M(x)\end{pmatrix}$

> [!example]+ Voorbeeld  
> Bij [[3. Polynomial regression#Polynomial regression|polynomial regression]] met één oorspronkelijke feature $x$ is $x$ een **scalair**.
> 
> Voor [[1. Polynoom#Graad|graad]] $3$ kan de feature mapping zijn:
> 
> $\boldsymbol{\phi}(x)=\begin{pmatrix}1\\x\\x^2\\x^3\end{pmatrix}$
> 
> Hierbij zijn:
> 
> $\phi_0(x)=1,\quad\phi_1(x)=x,\quad\phi_2(x)=x^2,\quad\phi_3(x)=x^3$
> 
> de basisfuncties.
> 
> De scalaire input $x$ wordt hiermee omgezet naar een feature vector met vier componenten.
> 
> Bij polynomial regression liggen deze basisfuncties vooraf vast zodra de graad is gekozen; ze worden niet tijdens training geleerd.
