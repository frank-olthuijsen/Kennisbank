## Feature engineering

> [!info] Feature engineering  
> **Feature engineering** is het proces waarbij [[2. Feature, label en target#Feature|features]] worden geselecteerd, gecreëerd of getransformeerd om data geschikter te maken voor het trainen van een machine-learningmodel.
> 
> Feature engineering kan onder andere bestaan uit:
> 
> - [[1. Feature engineering#Feature selection|feature selection]]: bestaande features selecteren     
> - [[1. Feature engineering#Feature extraction|feature extraction]]: nieuwe features afleiden door bestaande data te transformeren     
> - [[1. Feature engineering#Feature creation|feature creation]]: nieuwe features construeren uit bestaande of aanvullende data
> - features transformeren, bijvoorbeeld met [[4. Feature scaling#Feature scaling|feature scaling]], [[3. One-hot encoding#One-hot encoding|one-hot encoding]] of [[5. Bucketizing#Bucketizing|bucketizing]].     

> [!example]+ Voorbeeld  
> Een dataset bevat de lengte en het gewicht van patiënten.
> 
> Door hieruit BMI te berekenen wordt een nieuwe feature gecreëerd. Dit is **feature engineering**.
## Feature selection

> [!info] Feature selection  
> **Feature selection** is het selecteren van een subset van de bestaande [[2. Feature, label en target#Feature|features]] die relevant zijn voor een bepaalde analyse of machine-learningtask.
> 
> De geselecteerde features blijven daarbij zelf ongewijzigd. Irrelevante, redundante of ongewenste features worden weggelaten.
> 
> Feature selection kan worden gebruikt om het aantal dimensies van een dataset te verminderen.

> [!example]+ Voorbeeld  
> Een dataset bevat 50 patiëntkenmerken. Voor een bepaald model blijken slechts 12 daarvan relevant.
> 
> Door alleen deze 12 bestaande features te behouden en de overige 38 weg te laten, wordt **feature selection** toegepast.
## Feature extraction

> [!info] Feature extraction  
> **Feature extraction** is het transformeren van bestaande [[2. Feature, label en target#Feature|features]] naar een nieuwe set features die relevante informatie uit de oorspronkelijke data vertegenwoordigt.
> 
> In tegenstelling tot [[1. Feature engineering#Feature selection|feature selection]] worden dus niet alleen bestaande features gekozen, maar worden **nieuwe features gevormd uit de oorspronkelijke features**.
> 
> Feature extraction wordt vaak gebruikt voor [[1. Dimensionality reduction#Dimensionality reduction|dimensionality reduction]], waarbij veel oorspronkelijke features worden vervangen door een kleiner aantal nieuwe features.

> [!example]+ Voorbeeld  
> Een dataset bevat 50 numerieke features per patiënt.
> 
> Met **principal component analysis (PCA)** kunnen deze 50 oorspronkelijke features worden getransformeerd naar bijvoorbeeld 5 nieuwe features, de _principal components_, die een groot deel van de variatie in de oorspronkelijke data behouden. 
## Feature creation

> [!info] Feature creation
> **Feature creation** is het construeren van nieuwe [[2. Feature, label en target#Feature|features]] uit bestaande of aanvullende data, met als doel relevante informatie beschikbaar te maken voor een machine-learningmodel.
>
> Nieuwe features kunnen bijvoorbeeld worden gecreëerd door:
> - bestaande features rekenkundig te combineren;
> - aanvullende informatie uit andere databronnen toe te voegen;
> - nieuwe kenmerken af te leiden uit bestaande gegevens.
>
> Feature creation is een onderdeel van [[1. Feature engineering#Feature engineering|feature engineering]].
>
> Het onderscheid met [[1. Feature engineering#Feature extraction|feature extraction]] is niet altijd scherp. Bij feature creation ligt de nadruk doorgaans op het expliciet construeren van nieuwe kenmerken, terwijl feature extraction vaak bestaande data omzet naar een nieuwe representatie.

> [!example]+ Voorbeeld
> Een dataset bevat de lengte en het gewicht van patiënten.
>
> Hieruit wordt een nieuwe feature, BMI, berekend:
>
> $BMI=\frac{\text{gewicht (kg)}}{\text{lengte (m)}^2}$
>
> Deze nieuwe feature combineert twee bestaande features tot een kenmerk dat mogelijk relevanter is voor het model.
