## Sliding window

> [!info] Sliding window  
> Een **sliding window** is een techniek waarbij een venster met een vast aantal opeenvolgende observations over een [[2. Time series#Time series|time series]] wordt verschoven, zodat telkens een nieuw deel van de reeks wordt geselecteerd.
> 
> Voor een window size van $w$ bevat het venster op tijdstip $t$ bijvoorbeeld:
> 
> $x_{t-w+1},\dots,x_{t-1},x_t$
> 
> Wanneer het venster één tijdstap opschuift, wordt de oudste observation verwijderd en wordt de volgende observation toegevoegd.
> 
> Sliding windows worden onder andere gebruikt om:
> 
> - [[4. Lag feature#Lag feature|lag features]] te construeren;     
> - opeenvolgende delen van een time series als input voor een model te gebruiken;     
> - rolling statistics, zoals een moving average, te berekenen.     
> 
> De **window size** bepaalt hoeveel opeenvolgende tijdstappen ieder venster bevat.
> 
> Engels ook: **rolling window**

> [!example]+ Voorbeeld  
> Voor de time series:
> 
> $10,12,15,14,18$
> 
> en een window size van $3$ ontstaan achtereenvolgens:
> 
> $[10,12,15]$
> 
> $[12,15,14]$
> 
> $[15,14,18]$
> 
> Het venster schuift steeds één tijdstap naar rechts, waarbij de oudste waarde verdwijnt en een nieuwe waarde wordt toegevoegd.
