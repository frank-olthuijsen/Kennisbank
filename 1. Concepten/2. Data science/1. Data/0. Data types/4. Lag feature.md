## Lag feature

> [!info] Lag feature  
> Een **lag feature** is een [[3. Lag#Lag|lagged]] waarde uit een [[2. Time series#Time series|time series]] die als [[2. Feature, label en target#Feature|feature]] wordt gebruikt om een huidige of toekomstige waarde te voorspellen.
> 
> Als $x_t$ de waarde op tijdstip $t$ is, kan bijvoorbeeld $x_{t-1}$ als feature worden gebruikt voor het voorspellen van $x_t$:
> 
> $x_t=f(x_{t-1})$
> 
> Hierbij is $x_{t-1}$ een **lag feature met lag 1**.
> 
> Meer algemeen kan een model meerdere lag features gebruiken:
> 
> $x_t=f(x_{t-1},x_{t-2},\dots,x_{t-k})$
> 
> waarbij iedere eerdere waarde een afzonderlijke lag feature vormt.
> 
> Lag features maken [[2. Time series#Temporal|temporele]] informatie expliciet beschikbaar voor een model door eerdere observations om te zetten in input features.

> [!example]+ Voorbeeld  
> Een model voorspelt de temperatuur van vandaag op basis van eerdere temperaturen.
> 
> Mogelijke lag features zijn:
> 
> - temperatuur van gisteren: $x_{t-1}$;
>     
> - temperatuur van twee dagen geleden: $x_{t-2}$;
>     
> - temperatuur van zeven dagen geleden: $x_{t-7}$.
>     
> 
> Deze waarden vormen samen de input waarmee het model de huidige temperatuur $x_t$ kan voorspellen.
