## Data pipeline

> [!info] Data pipeline
> Een **data pipeline** is een geautomatiseerde of herhaalbare reeks stappen waarmee data vanuit één of meer bronnen wordt verzameld, verwerkt en doorgegeven aan een bestemming waar de data verder kan worden gebruikt.
> 
> Tijdens deze stappen kan data bijvoorbeeld worden opgeschoond, gecombineerd of getransformeerd.
### Architectuur en fouttolerantie

Data pipelines bestaan vaak uit meerdere componenten die data stapsgewijs verwerken.

- Componenten draaien vaak **asynchroon** ten opzichte van elkaar.    
- Iedere component werkt min of meer zelfstandig.    
- De **data store** tussen componenten kan fungeren als interface: een component schrijft zijn resultaat weg, waarna een volgende component deze data later kan verwerken.    
- Als een component tijdelijk faalt, kunnen achterliggende componenten soms blijven doorwerken op basis van eerder opgeslagen data.    
- Hierdoor zijn componenten minder sterk direct van elkaar afhankelijk.    
- Goede **monitoring** is hierbij belangrijk, zodat snel wordt opgemerkt wanneer een component niet meer functioneert of wanneer verouderde data wordt verwerkt.
