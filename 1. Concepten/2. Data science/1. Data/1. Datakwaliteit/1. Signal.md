## Signal

> [!info] Signal  
> **Signal** is de betekenisvolle informatie of het onderliggende patroon in data dat relevant is voor wat je probeert te meten, verklaren of voorspellen.
> 
> Signal staat tegenover [[2. Noise|noise]]: signal bevat bruikbare informatie, terwijl noise bestaat uit willekeurige of irrelevante variatie die het patroon moeilijker herkenbaar maakt.

> [!example]+ Voorbeeld  
> Een model probeert te voorspellen welke patiënten een verhoogd risico hebben op heropname.
> 
> Een werkelijk verband tussen bepaalde patiëntkenmerken en heropname vormt **signal** in de data. Meetfouten, toevallige schommelingen en verkeerd ingevoerde waarden kunnen daarentegen **noise** vormen.

## Relatie tussen signal en feature

Een [[2. Feature, label en target|feature]] is een concrete invoervariabele van een model. **Signal** is de bruikbare informatie in de data waarmee het model iets over de target kan leren.

- Een feature kan veel signal bevatten.
- Een feature kan weinig signal bevatten.
- Een feature kan geen relevant signal bevatten.
- Een feature kan zowel signal als [[1. Noise|noise]] bevatten.
- Relevant signal kan ook pas ontstaan uit de combinatie van meerdere features.

Schematisch:

`feature = mogelijk signal + noise`
