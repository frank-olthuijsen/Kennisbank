## Doel

`2. Toepassing` bevat praktische manieren om concepten uit de kennisbank toe te passen met programmeertalen, libraries, frameworks en andere tools.

De nadruk ligt op:

```text
wat wil ik doen? → welke oplossingen bestaan hiervoor? → hoe gebruik ik deze?
```

Niet op:

```text
welke functies bevat library X?
```

## Structuur

- Groepeer onderwerpen primair op **doel, handeling of probleem**, niet op library.
- Plaats oplossingen uit verschillende libraries die hetzelfde doel dienen bij voorkeur op dezelfde pagina.
- Maak dus bijvoorbeeld één pagina:

```text

```

met daarin oplossingen via bijvoorbeeld:

```text

```

in plaats van afzonderlijke pagina's onder:

```text

```

- Maak alleen een library- of toolgerichte structuur wanneer het onderwerp daadwerkelijk specifiek is voor die library of tool.
- Houd rekening met toekomstige uitbreiding met bijvoorbeeld:
  - Python;
  - pandas;
  - NumPy;
  - Matplotlib;

  - scikit-learn;

## Code

- Gebruik fenced code blocks met de juiste taal:

```python
df.groupby("city")["temperature"].mean()
```

- Codevoorbeelden moeten bij voorkeur:
  - klein zijn;
  - zelfstandig te begrijpen zijn;
  - alleen relevante code bevatten;
  - gangbare en actuele syntax gebruiken.
- Vermijd grote volledige scripts wanneer een klein voorbeeld hetzelfde concept duidelijk maakt.
- Gebruik commentaar in code alleen wanneer dit daadwerkelijk helpt om een niet-direct-zichtbare stap uit te leggen.
- Geef inhoudelijke uitleg bij voorkeur in de Markdown rondom het codeblok in plaats van iedere regel code van commentaar te voorzien.

Goed:

```python
mask = df["target"].isin([0, 2])
df_selected = df.loc[mask].copy()
```

Met daarna uitleg in Markdown.

Gebruik dus niet standaard:

```python
# Maak een mask
mask = df["target"].isin([0, 2])

# Selecteer de rijen
df_selected = df.loc[mask]

# Maak een kopie
df_selected = df_selected.copy()
```

## Voorbeelden

Plaats volledige voorbeelden waar passend in een uitklapbare `example`-callout:

> sns.pairplot(
>     data=df,
>     vars=features,
>     hue="target"
> )
> ```
```

Gebruik kleinere codefragmenten buiten een example-callout wanneer ze alleen dienen om één parameter of syntactisch onderdeel te verduidelijken.

## Parameters en argumenten

Leg belangrijke parameters uit wanneer hun betekenis niet direct duidelijk is.

Bijvoorbeeld:

```python
sns.pairplot(
    data=df,
    vars=features,
    hue="target"
)
```

Leg daarna bijvoorbeeld uit:

- `data`: de gebruikte DataFrame;
- `vars`: de features die worden gevisualiseerd;
- `hue`: de variabele waarmee observations visueel worden onderscheiden.

Behandel alleen parameters die nuttig zijn voor begrip of veelvuldig gebruik. Maak geen volledige kopie van de API-documentatie.

## Meerdere oplossingen

Wanneer verschillende libraries of technieken hetzelfde probleem oplossen:

- leg de belangrijkste verschillen uit;
- geef aan wanneer een verschil praktisch relevant is;
- voorkom dat dezelfde uitleg volledig wordt herhaald.

Bijvoorbeeld:

```text

```

## Vergelijkingen

Gebruik een tabel wanneer twee of meer oplossingen zinvol naast elkaar kunnen worden gezet.

Bijvoorbeeld:

```markdown
| Eigenschap | pandas `scatter_matrix()` | Seaborn `pairplot()` |
| --- | --- | --- |
| Features selecteren | DataFrame selecteren | `vars=` |
| Classes kleuren | `c=` | `hue=` |
| Legend | Beperkt | Automatisch |
```

Vergelijk alleen eigenschappen die helpen bij het kiezen of begrijpen van de oplossingen.

## Interpretatie

Leg waar relevant niet alleen uit **hoe** de code werkt, maar ook **hoe de output moet worden geïnterpreteerd**.

Bij visualisaties kan dit bijvoorbeeld betekenen:

- wat een patroon betekent;
- wat clusters kunnen aangeven;
- wat een opvallende observation kan betekenen;
- welke conclusies niet uit de visualisatie mogen worden getrokken.

Verwijs voor onderliggende theorie naar `1. Concepten`.
