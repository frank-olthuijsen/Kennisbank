## `cross_val_predict()`

Maakt voor **iedere observation** in een dataset één *out-of-fold prediction* met behulp van [[3. Cross-validation#k-fold cross-validation|cross-validation]].

``` python
from sklearn.model_selection import cross_val_predict

scores_sgd = cross_val_predict(
    model,
    X_train,
    y_train,
    cv=3,
    method="decision_function"
)
```

Bij `cv=3` wordt het model drie keer getraind. Iedere keer worden twee folds gebruikt voor training en wordt de overgebleven fold gebruikt om de prediction te berekenen. Iedere _observation_ krijgt daardoor een prediction van een model dat deze _observation_ **niet tijdens training heeft gezien**. 

De predictions worden daarna weer samengevoegd in de oorspronkelijke volgorde van de _observations_.
### `model`

Dit is conceptueel een ongetrainde [[1. Estimator#Estimator|estimator]].

Bij iedere fold gebeurt grofweg:

```
estimator
    ↓
fit()
    ↓
getraind model
    ↓
prediction/output op validation fold
```

Afhankelijk van `method` is die output bijvoorbeeld:

- `predict` → _class prediction_
- `decision_function` → _decision score_
- `predict_proba` → _estimated probabilities_    

Bij `cross_val_predict()` wordt dus geen _performance score_ berekend. De out-of-fold predictions of andere modeloutputs worden teruggegeven.
### `Method`
Bepaalt welke methode van de getrainde estimator wordt aangeroepen op de validation fold.
#### `"decision_function"`

Hiermee wordt niet de voorspelde _class_ teruggegeven, maar de [[2. Decision score#Decision score|decision score]] van iedere _observation_.

Bij [[1. Binary classification#Binary classification|binary classification]] geldt doorgaans:

- een hogere positieve score wijst sterker richting de [[2. Positive class#Positive class|positive class]]
- een negatieve score wijst sterker richting de [[3. Negative class#Negative class|negative class]]   
- de standaard [[4. Decision threshold#Decision threshold|decision threshold]] voor een _decision function_ ligt meestal bij $0$.
#### `"predict_proba"`

Hiermee wordt voor iedere fold de `predict_proba()`-methode van de _estimator_ aangeroepen. Iedere _observation_ krijgt daardoor [[3. Estimated probability#Estimated probability|estimated probabilities]] van een model waarvoor die _observation_ niet tijdens training is gebruikt.

Bij _classification_ wordt voor per observation voor iedere class een _estimated probability_ teruggegeven, bijvoorbeeld:

```
[0.18, 0.82]
```
Deze probabilities kunnen vervolgens bijvoorbeeld worden vergeleken met een [[4. Decision threshold#Decision threshold|decision threshold]], waarvan standaardwaarde meestal bij $0.5$ ligt.

### Verschil met `cross_val_score()`

|Functie|Output|
|---|---|
|`cross_val_score()`|één performance score per fold|
|`cross_val_predict()`|één prediction of score per _observation_|

`cross_val_predict()` is daardoor bijvoorbeeld geschikt om op basis van out-of-fold predictions een **precision-recall curve**, **ROC curve** of een geschikte **decision threshold** te bepalen.
