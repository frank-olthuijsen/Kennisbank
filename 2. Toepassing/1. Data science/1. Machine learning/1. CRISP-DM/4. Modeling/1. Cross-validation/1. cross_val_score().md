## cross_val_score()

Voert [[3. Cross-validation#k-fold cross-validation|cross-validation]] uit en retourneert voor **iedere fold** één [[2. Performance score#Performance score|performance score]].

```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(
    model,
    X_train,
    y_train,
    cv=5,
    scoring="recall"
)
```

Bij `cv=5` wordt het model vijf keer getraind. Iedere keer worden vier folds gebruikt voor training en wordt de overgebleven fold gebruikt om de gekozen [[1. Performance metric#Performance metric|performance metric]] te berekenen, in dit geval [[3. Precision, recall en specificity#Recall|recall]].

Het resultaat bevat daardoor vijf scores, bijvoorbeeld:

```
[0.78 0.81 0.76 0.80 0.79]
```
### `model`

Dit is conceptueel een ongetrainde [[1. Estimator#Estimator|estimator]].

Bij iedere fold gebeurt grofweg:

```
estimator
    ↓
fit()
    ↓
getraind model
    ↓
predictions op validation fold
    ↓
performance score
```
