## cross_validate()

Voert [[3. Cross-validation#k-fold cross-validation|cross-validation]] uit en retourneert voor **iedere fold** meerdere resultaten, waaronder één of meer [[2. Performance score#Performance score|performance scores]] en informatie over de benodigde rekentijd.

```
from sklearn.model_selection import cross_validate

results = cross_validate(
    model,
    X_train,
    y_train,
    cv=5,
    scoring=["accuracy", "precision", "recall"]
)
```

Bij `cv=5` wordt het model vijf keer getraind. Iedere keer worden vier folds gebruikt voor training en wordt de overgebleven fold gebruikt om de gekozen [[Kennisbank/1. Concepten/2. Data science/0. Basisbegrippen/6. Evaluation/1. Performance metric#Performance metric|performance metrics]] te berekenen.

In tegenstelling tot `cross_val_score()` kunnen met `cross_validate()` meerdere _performance metrics_ tegelijk worden berekend.

Het resultaat is een dictionary met onder andere:

```
results["test_accuracy"]
results["test_precision"]
results["test_recall"]
results["fit_time"]
results["score_time"]
```

Iedere array bevat één waarde per fold.

### `model`

Dit is conceptueel een ongetrainde [[1. Estimator#Estimator|estimator]].

Bij iedere fold gebeurt grofweg:

```
estimator
    ↓
fit()
    ↓
getraind model
    ↓
predictions op validation fold
    ↓
performance metrics
```

### `scoring`

Bepaalt welke _performance metric_ of _performance metrics_ worden berekend.

Voor één metric kan bijvoorbeeld worden gebruikt:

```
scoring="recall"
```

Voor meerdere metrics:

```
scoring=["accuracy", "precision", "recall"]
```

De scores worden dan afzonderlijk in het resultaat opgenomen, bijvoorbeeld als `test_accuracy`, `test_precision` en `test_recall`.

### Verschil met `cross_val_score()` en `cross_val_predict()`

|Functie|Output|
|---|---|
|`cross_val_score()`|één performance score per fold|
|`cross_validate()`|één of meer performance scores en aanvullende informatie per fold|
|`cross_val_predict()`|één prediction of score per _observation_|

`cross_validate()` is daardoor vooral geschikt wanneer meerdere _performance metrics_ van hetzelfde model tijdens dezelfde cross-validation moeten worden vergeleken.
