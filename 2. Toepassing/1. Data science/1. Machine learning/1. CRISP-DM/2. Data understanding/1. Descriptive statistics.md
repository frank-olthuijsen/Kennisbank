## Descriptive statistics

> [!info] Descriptive statistics  
> **Descriptive statistics** worden gebruikt om de belangrijkste eigenschappen van een dataset samen te vatten en te onderzoeken.
> 
> In pandas kunnen onder andere `df.info()`, `df.describe()` en `df.corr()` worden gebruikt voor een eerste inspectie van een dataset.

Deze methoden beantwoorden verschillende vragen:

|Methode|Vraag|
|---|---|
|`df.info()`|Hoe is de dataset technisch opgebouwd?|
|`df.describe()`|Hoe zijn de waarden in afzonderlijke features verdeeld?|
|`df.corr()`|Hoe sterk hangen numerieke features lineair met elkaar samen?|

## `df.info()`

`df.info()` geeft een compacte technische samenvatting van een DataFrame.

```python
df.info()
```

De output bevat onder andere:

- het aantal observations;
    
- de kolomnamen;
    
- het aantal non-null values per kolom;
    
- het datatype (`dtype`) van iedere kolom;
    
- het geheugengebruik.
    

`df.info()` is daarom vooral nuttig als eerste controle van een dataset. Hiermee kunnen bijvoorbeeld ontbrekende waarden of onverwachte datatypes snel worden ontdekt.

De methode toont de informatie in de output en retourneert deze niet als een nieuwe DataFrame.

## `df.describe()`

`df.describe()` berekent verschillende descriptive statistics voor de numerieke features:

```python
df.describe()
```

Standaard bevat de output:

|Waarde| Betekenis                                |
|---|---|
|`count`| Aantal non-null observations             |
|`mean`| [[1. Centrummaten#Rekenkundig gemiddelde |
|`std`| [[2. Spreidingsmaten#Standaarddeviatie]] |
|`min`| Kleinste waarde                          |
|`25%`| Eerste kwartiel                          |
|`50%`| Mediaan                                  |
|`75%`| Derde kwartiel                           |
|`max`| Grootste waarde                          |

Hiermee kan snel worden onderzocht waar waarden ongeveer liggen en hoeveel spreiding er binnen iedere feature aanwezig is.

Ook niet-numerieke features kunnen worden meegenomen:

```python
df.describe(include="all")
```

De weergegeven statistieken hangen dan af van het datatype van de feature.

## `df.corr()`

`df.corr()` berekent de pairwise _correlation_ tussen numerieke features.

```python
df.corr(numeric_only=True)
```

Standaard wordt de [[2. Correlatiecoëfficiënt#Pearson-correlatiecoëfficiënt|Pearson-correlatiecoëfficiënt]] gebruikt.

Het resultaat is een correlation matrix, bijvoorbeeld:

```text
          age    weight   height
age       1.00     0.32     0.18
weight    0.32     1.00     0.71
height    0.18     0.71     1.00
```

Iedere waarde geeft de sterkte en richting van de lineaire samenhang tussen twee features aan.

De diagonaal bevat altijd `1`, omdat iedere feature perfect met zichzelf correleert. De matrix is symmetrisch: de correlation tussen `weight` en `height` is dezelfde als tussen `height` en `weight`.

Andere correlation methods kunnen met `method` worden gekozen:

```python
df.corr(method="pearson", numeric_only=True)
df.corr(method="spearman", numeric_only=True)
df.corr(method="kendall", numeric_only=True)
```

Een hoge correlation betekent niet dat de ene feature de andere veroorzaakt. Daarnaast kan een lage Pearson correlation voorkomen terwijl er wel een sterke niet-lineaire relatie bestaat. Bekijk relaties daarom waar relevant ook visueel, bijvoorbeeld met een [[2. Scatterplot matrix|scatterplot matrix]].

## Eerste inspectie van een dataset

Deze methoden kunnen samen worden gebruikt voor een snelle eerste inspectie:

```python
df.info()
df.describe()
df.corr(numeric_only=True)
```

Daarbij geeft:

- `info()` inzicht in de structuur en datakwaliteit;
    
- `describe()` inzicht in de verdeling van individuele features;
    
- `corr()` inzicht in lineaire relaties tussen features.
    

Ze vormen daarmee een nuttig beginpunt voor _exploratory data analysis_.
