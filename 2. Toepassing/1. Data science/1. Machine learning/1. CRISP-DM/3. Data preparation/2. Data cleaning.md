### SimpleImputer
[API reference](https://scikit-learn.org/stable/modules/generated/sklearn.impute.SimpleImputer.html) 

Wordt gebruikt om ontbrekende waarden (`NaN`) in features te vervangen.

```python
from sklearn.impute import SimpleImputer # KNNImputer/IterativeImputer

imputer = SimpleImputer(strategy="median") # mean/most_frequent/constant(fill_value)
housing_num = housing.select_dtypes(include=[np.number]) # median, daarom de niet-numerieke waarden uitfilteren

# optie 1
imputer.fit(housing_num) # bepaalt per feature waarmee ontbrekende waarden moeten worden vervangen
X = imputer.transform(housing_num) # vervangt de ontbrekende waarden

# optie 2
fit_transform() # voert beide stappen achter elkaar uit.
```

- Voor iedere numerieke feature wordt afzonderlijk de relevante waarde berekend over de niet-ontbrekende waarden.
- De ontbrekende waarden worden vervolgens hierdoor vervangen.
- Ook wanneer een feature geen ontbrekende waarden bevat is het goed om de imputer te gebruiken. Bij nieuwe data kan het zijn dat er wel gegevens ontbreken.
- Bij machine learning wordt de imputer alleen op de training data gefit.
- Dezelfde imputer wordt vervolgens gebruikt voor de test data.
- Hierdoor worden voor de test data dezelfde waarden gebruikt die uit de training data zijn geleerd en voorkom je data leakage.

Meer geavanceerde imputers zijn:
- [KNNImputer](https://scikit-learn.org/stable/modules/generated/sklearn.impute.KNNImputer.html)
- [IterativeImputer](https://scikit-learn.org/stable/modules/generated/sklearn.impute.IterativeImputer.html)
