## Pipeline

> [!info] Pipeline  
> Een **Pipeline** is in scikit-learn een [[1. Estimator#Estimator|estimator]] die meerdere estimators achter elkaar uitvoert en als één estimator beschikbaar maakt.
> 
> Alle tussenstappen zijn [[2. Transformer#Transformer|transformers]]. Tijdens `fit()` wordt iedere transformer achtereenvolgens gefit en wordt zijn output doorgegeven aan de volgende stap. De laatste estimator wordt vervolgens gefit op de getransformeerde data.
> 
> De laatste estimator bepaalt welke uiteindelijke functionaliteit de pipeline heeft. Is de laatste stap bijvoorbeeld een _classifier_, dan kan de pipeline als geheel predictions maken met `predict()`.
> 
> Een pipeline zorgt er daarnaast voor dat preprocessing tijdens bijvoorbeeld cross-validation binnen iedere training fold opnieuw wordt gefit. Hierdoor helpt een pipeline _data leakage_ te voorkomen.

> [!example]+ Voorbeeld  
> Een `StandardScaler` en `LogisticRegression` kunnen als één estimator worden gecombineerd:
> 
> ```
> from sklearn.pipeline import Pipeline
> from sklearn.preprocessing import StandardScaler
> from sklearn.linear_model import LogisticRegression
> 
> pipeline = Pipeline([
>     ("scaler", StandardScaler()),
>     ("classifier", LogisticRegression())
> ])
> ```
> 
> Met:
> 
> ```
> pipeline.fit(X_train, y_train)
> ```
> 
> wordt eerst `StandardScaler` gefit op `X_train` en wordt de getransformeerde data gebruikt om `LogisticRegression` te fitten.
> 
> Daarna kan de volledige pipeline als één estimator worden gebruikt:
> 
> ```
> y_pred = pipeline.predict(X_test)
> ```
> 
> `X_test` wordt daarbij eerst met dezelfde `StandardScaler` getransformeerd, waarna `LogisticRegression` de predictions maakt.
