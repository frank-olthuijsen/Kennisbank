## ColumnTransformer

> [!info] ColumnTransformer  
> Een **ColumnTransformer** is in scikit-learn een [[2. Transformer#Transformer|transformer]] waarmee verschillende transformers op verschillende subsets van de _features_ kunnen worden toegepast.
> 
> Tijdens `fit()` wordt iedere transformer gefit op de kolommen die eraan zijn toegewezen. Tijdens `transform()` worden deze transformers op dezelfde kolommen toegepast en worden hun outputs samengevoegd tot één nieuwe _feature space_.
> 
> Een `ColumnTransformer` is vooral nuttig wanneer een dataset verschillende typen _features_ bevat die verschillende preprocessing nodig hebben, bijvoorbeeld:
> 
> - numerieke _features_ die geschaald moeten worden;
>     
> - categorische _features_ die geëncodeerd moeten worden.
>     
> 
> De parameter `transformers` bevat tuples met de vorm:
> 
> ```
> (name, transformer, columns)
> ```
> 
> Hiermee wordt vastgelegd welke transformer op welke kolommen wordt toegepast.
> 
> Kolommen die niet expliciet worden geselecteerd, worden standaard verwijderd. Met `remainder="passthrough"` kunnen deze ongewijzigd worden doorgegeven.

> [!example]+ Voorbeeld  
> Stel dat een dataset de numerieke _features_ `age` en `income` bevat en de categorische _feature_ `sex`:
> 
> ```
> from sklearn.compose import ColumnTransformer
> from sklearn.preprocessing import OneHotEncoder, StandardScaler
> 
> preprocessing = ColumnTransformer([
>     ("numeric", StandardScaler(), ["age", "income"]),
>     ("categorical", OneHotEncoder(), ["sex"])
> ])
> ```
> 
> Met:
> 
> ```
> preprocessing.fit(X_train)
> ```
> 
> wordt `StandardScaler` gefit op `age` en `income` en wordt [[1. OneHotEncoder#OneHotEncoder|OneHotEncoder]] gefit op `sex`.
> 
> Vervolgens:
> 
> ```
> X_train_transformed = preprocessing.transform(X_train)
> ```
> 
> past beide transformers toe op hun eigen kolommen en voegt de resultaten samen tot één getransformeerde dataset.
