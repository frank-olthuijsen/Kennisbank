## ClassifierChain

Een [[1. Estimator#Estimator|estimator]] die een [[1. Classifier chain#Classifier chain|classifier chain]] implementeert voor _multilabel classification_.

```python
from sklearn.multioutput import ClassifierChain
```

De class krijgt een basis-_classifier_ mee via `estimator`. Voor ieder _label_ wordt daarvan een afzonderlijke _estimator_ gebruikt. De _estimators_ worden vervolgens volgens `order` in een keten geplaatst.

```
features
    ↓
estimator label 1
    ↓
features + output label 1
    ↓
estimator label 2
    ↓
features + outputs label 1 en 2
    ↓
...
```

|Eigenschap|`ClassifierChain`|
|---|---|
|**Transformer**|-|
|**Predictor**|_multilabel predictions_ via `predict()`|
|Modeltype|[[1. Classifier chain#Classifier chain\|classifier chain]]|
|`estimator`|basis-_classifier_ waaruit de afzonderlijke _estimators_ in de keten worden opgebouwd|
|`order`|bepaalt de volgorde waarin de _labels_ in de keten worden voorspeld|
|`chain_method`|bepaalt welke output van eerdere _estimators_ als extra _features_ wordt doorgegeven|
|`cv`|bepaalt of tijdens training werkelijke eerdere _labels_ of cross-validated _predictions_ als extra _features_ worden gebruikt|
|`predict_proba()`|geeft _estimated probabilities_ voor de afzonderlijke _labels_ terug|

### `order`

Met `order=None` volgt de keten de volgorde van de kolommen in de _target data_. Met `order="random"` wordt een willekeurige volgorde gebruikt.

Omdat eerdere outputs als input voor latere _estimators_ dienen, kan de gekozen volgorde invloed hebben op de uiteindelijke _predictions_.

### `chain_method`

`chain_method` bepaalt welke output van een eerdere _estimator_ als extra _feature_ aan de volgende _estimator_ wordt doorgegeven.

Standaard:

```
chain_method="predict"
```

Hierbij worden de _class predictions_ van eerdere _estimators_ gebruikt. Afhankelijk van de basis-_estimator_ kunnen ook andere outputs, zoals `predict_proba()` of `decision_function()`, worden gebruikt.

### `cv`

Standaard is:

```
cv=None
```

Tijdens `fit()` gebruikt scikit-learn dan de **werkelijke eerdere labels** als extra _features_.

Wanneer `cv` wordt ingesteld, gebruikt scikit-learn daarvoor cross-validated _predictions_. Hierdoor lijkt de informatie die latere _estimators_ tijdens training krijgen meer op de situatie tijdens prediction, waarin de werkelijke labels niet beschikbaar zijn.
