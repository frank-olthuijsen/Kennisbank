## OneHotEncoder

[API reference](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.OneHotEncoder.html)

Een [[2. Transformer#Transformer|transformer]] uit scikit-learn die [[3. One-hot encoding#One-hot encoding|one-hot encoding]] toepast op categorische *features*.

```python
from sklearn.preprocessing import OneHotEncoder
```

Tijdens `fit()` bepaalt de transformer welke categorieën in de *training data* voorkomen. Met `transform()` worden deze categorieën omgezet naar binaire *features*.

Dezelfde categorieën en volgorde worden vervolgens gebruikt bij het transformeren van **nieuwe** data.

| Eigenschap | `OneHotEncoder` |
|---|---|
| **Transformer** | Categorische features omzetten naar binaire features |
| **Predictor** | - |
| `fit()` | Bepaalt de categorieën per feature |
| `transform()` | Zet categorieën om naar een numerieke representatie |
| `fit_transform()` | Voert beide stappen achter elkaar uit |
| `categories_` | Bevat de tijdens `fit()` bepaalde categorieën |
| `handle_unknown` | Bepaalt hoe onbekende categorieën tijdens `transform()` worden verwerkt |
| `sparse_output` | Bepaalt of de output een sparse matrix of een dense array is |
| `drop` | Bepaalt of bepaalde categorieën worden weggelaten uit de output |
