## `RandomForestClassifier`

`RandomForestClassifier` is een [[1. Estimator#Estimator|estimator]] uit scikit-learn waarmee een [[2. Random forest#Random forest|random forest]] voor _classification_ wordt getraind.

```python
from sklearn.ensemble import RandomForestClassifier
```

Het model bestaat uit meerdere [[1. Decision tree#Decision tree|decision trees]]. Iedere tree wordt getraind met willekeur in zowel de gebruikte _training observations_ als de _features_ die bij splitsingen worden overwogen. De outputs van de trees worden vervolgens gecombineerd.

| Eigenschap | `RandomForestClassifier` |
| --- | --- |
| **Transformer** | - |
| **Predictor** | *class predictions* via `predict()` |
| Modeltype | random forest *classification model* |
| Multiclass | meerdere *classes* direct |
| `decision_function()` | - |
| `predict_proba()` | *estimated probabilities* door de probabilities van de afzonderlijke trees te middelen |
| `partial_fit()` | - |
| `feature_importances_` | relatieve importance van de *features* |

Bij `predict()` combineert scikit-learn de trees via hun _estimated probabilities_: de _class_ met de hoogste gemiddelde probability over de trees wordt voorspeld.
