## KNeighborsClassifier

[API reference](https://scikit-learn.org/stable/modules/generated/sklearn.neighbors.KNeighborsClassifier.html)

```python
from sklearn.neighbors import KNeighborsClassifier
```

`KNeighborsClassifier` is een [[1. Estimator#Estimator|estimator]] uit scikit-learn die een _class prediction_ maakt op basis van de _classes_ van de $k$ dichtstbijzijnde observations in de _training data_.

| Eigenschap            | `KNeighborsClassifier`                                                                                                                  |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Transformer**       | -                                                                                                                                       |
| **Predictor**         | _class predictions_ via `predict()`                                                                                                     |
| Modeltype             | _k-nearest neighbors classifier_; _instance-based learning_                                                                             |
| Multiclass            | meerdere _classes_ rechtstreeks ondersteund                                                                                             |
| `decision_function()` | -                                                                                                                                       |
| `predict_proba()`     | [[3. Estimated probability#Estimated probability\|estimated probabilities]] op basis van de _classes_ van de dichtstbijzijnde neighbors |
| `partial_fit()`       | -                                                                                                                                       |
| `n_neighbors`         | aantal neighbors dat voor een prediction wordt gebruikt; standaard `5`                                                                  |
| `weights`             | bepaalt hoeveel invloed iedere neighbor op de prediction heeft                                                                          |
| `metric`              | bepaalt hoe de afstand tussen observations wordt berekend                                                                               |

Tijdens `fit()` wordt geen parametrisch model geleerd. De _training data_ wordt opgeslagen zodat tijdens `predict()` voor iedere nieuwe observation de dichtstbijzijnde neighbors kunnen worden bepaald.
