## SGDClassifier
[API reference](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.SGDClassifier.html)

`SGDClassifier` is een [[1. Estimator#Estimator|estimator]] uit scikit-learn waarmee **lineaire classification models** worden getraind met [[1. Gradient descent#Stochastic gradient descent|stochastic gradient descent]].

```python
from sklearn.linear_model import SGDClassifier
```

| Eigenschap            | `SGDClassifier`                                                                                                                                         |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Transformer**       | -                                                                                                                                                       |
| **Predictor**         | *class predictions* via `predict()`                                                                                                                     |
| Modeltype             | lineair *classification model*; welke precies is afhankelijk van `loss`                                                                                 |
| Multiclass            | meerdere *classes* via one-vs-rest                                                                                                                      |
| `decision_function()` | [[2. Decision score#Decision score\|decision scores]]                                                                                                   |
| `predict_proba()`     | [[3. Estimated probability#Estimated probability\|estimated probabilities]] bij `loss="log_loss"` of `loss="modified_huber"`                            |
| `partial_fit()`       | incrementele training / *online learning*                                                                                                               |
| `loss`                | bepaald welke [[2. Loss function#Loss function\|loss function]] tijdens training wordt geminimaliseerd en daarmee welk type lineair model wordt geleerd |
| `loss="hinge"`        | lineaire [[1. Support vector machine (SVM)#Support vector machine (SVM)\|SVM]] (standaard)                                                              |
| `loss="log_loss"`     | [[1. Logistic regression#Logistic regression\|logistic regression]]                                                                                     |
