## `LogisticRegression`

`LogisticRegression` is een [[1. Estimator#Estimator|estimator]] uit scikit-learn waarmee een [[1. Logistic regression#Logistic regression|logistic regression]] model wordt getraind.

```python
from sklearn.linear_model import LogisticRegression
```

De `solver` bepaalt welk [[3. Optimization algorithm#Optimization algorithm|optimization algorithm]] wordt gebruikt om de parameters van het logistic regression model te leren.

|Eigenschap|`LogisticRegression`|
|---|---|
|**Transformer**|-|
|**Predictor**|_class predictions_ via `predict()`|
|Modeltype|logistic regression|
|Multiclass|meerdere _classes_; standaard multinomial bij geschikte `solver`|
|`decision_function()`|[[2. Decision score#Decision score\|decision scores]]|
|`predict_proba()`|[[3. Estimated probability#Estimated probability\|estimated probabilities]]|
|`partial_fit()`|-|
|`solver`|bepaalt het _optimization algorithm_ waarmee de modelparameters worden geleerd|
|`solver="lbfgs"`|standaard|
|`C`|bepaalt de sterkte van [[4. Regularization#Regularization\|regularization]]; kleinere waarde betekent sterkere regularization|

`LogisticRegression` past standaard regularization toe. De keuze van `solver` en regularization beïnvloedt de training, maar verandert niet dat het uiteindelijke model een logistic regression model is.
