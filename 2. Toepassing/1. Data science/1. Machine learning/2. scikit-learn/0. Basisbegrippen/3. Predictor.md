## Predictor

> [!info] Predictor  
> Een **predictor** is in scikit-learn een [[1. Estimator#Estimator|estimator]] die [[5. Prediction#Prediction|predictions]] kan produceren met `predict()` en/of `fit_predict()`.
> 
> Onder predictors vallen onder andere:
> 
> - _classifiers_;
>     
> - _regressors_;
>     
> - _outlier detectors_;
>     
> - _clusterers_.
>     
> 
> Een predictor leert doorgaans eerst uit data met `fit()`. Daarna kan `predict()` worden gebruikt om voor nieuwe data predictions te produceren.
> 
> Niet iedere estimator is een predictor. Een [[2. Transformer#Transformer|transformer]] kan bijvoorbeeld data transformeren zonder zelf predictions te produceren.

> [!example]+ Voorbeeld  
> `LogisticRegression` is een predictor omdat de estimator na training `predict()` kan gebruiken:
> 
> ```python
> from sklearn.linear_model import LogisticRegression
> 
> classifier = LogisticRegression()
> classifier.fit(X_train, y_train)
> 
> predictions = classifier.predict(X_test)
> ```
> 
> `predictions` bevat voor iedere observation in `X_test` de voorspelde class.
