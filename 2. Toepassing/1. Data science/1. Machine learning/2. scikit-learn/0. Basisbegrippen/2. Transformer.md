## Transformer

> [!info] Transformer  
> Een **transformer** is in scikit-learn een [[1. Estimator#Estimator|estimator]] die data omzet naar een andere representatie.
> 
> Een transformer leert indien nodig eerst informatie uit de data met:
> 
> ```
> transformer.fit(X)
> ```
> 
> Vervolgens kan dezelfde transformatie op data worden toegepast met:
> 
> ```
> X_transformed = transformer.transform(X)
> ```
> 
> Veel transformers bieden ook:
> 
> ```
> X_transformed = transformer.fit_transform(X)
> ```
> 
> waarmee `fit()` en `transform()` achtereenvolgens worden uitgevoerd.
> 
> Transformers worden bijvoorbeeld gebruikt voor:
> 
> - het schalen van _features_;
>     
> - het encoderen van categorische waarden;
>     
> - dimensionality reduction;
>     
> - het selecteren of construeren van _features_.
>     

> [!example]+ Voorbeeld  
> `StandardScaler` is een transformer geschikt voor [[4. Feature scaling#Standardization|standardization]]:
> 
> ```python
> from sklearn.preprocessing import StandardScaler
> 
> scaler = StandardScaler()
> scaler.fit(X_train)
> 
> X_train_scaled = scaler.transform(X_train)
> X_test_scaled = scaler.transform(X_test)
> ```
> 
> Met `fit()` leert de transformer uit `X_train` onder andere het gemiddelde en de standaarddeviatie van iedere _feature_.
> 
> Met `transform()` worden deze geleerde waarden vervolgens gebruikt om zowel de _training data_ als nieuwe data op dezelfde manier te schalen.
