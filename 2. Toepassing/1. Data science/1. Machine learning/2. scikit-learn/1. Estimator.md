## Estimator

> [!info] Estimator  
> Een **estimator** is in scikit-learn een object dat verantwoordelijk is voor het **fitten** van een model of transformatie aan data.
> 
> Met `fit()` gebruikt de estimator de _training data_ om de benodigde **geleerde parameters** of andere interne toestand te bepalen en op te slaan.
> 
> De instellingen die vóór `fit()` worden opgegeven zijn doorgaans _hyperparameters_. De waarden die tijdens `fit()` uit de data worden geleerd vormen de geleerde parameters of toestand van de estimator.
> 
> Een estimator kan bijvoorbeeld een:
> 
> - _classifier_;
>     
> - _regressor_;
>     
> - _transformer_;
>     
> - _clusterer_
>     
> 
> zijn.
> 
> Bij een _classifier_ of _regressor_ komt het fitten overeen met het trainen van een voorspellend model. Bij een _transformer_ worden bijvoorbeeld parameters geleerd die nodig zijn om data te transformeren.

> [!example]+ Voorbeeld  
> Bij:
> 
> ```python
> estimator = LogisticRegression(C=1.0)
> ```
> 
> is `C=1.0` een ingestelde _hyperparameter_. Er is nog geen model getraind.
> 
> Met:
> 
> ```python
> estimator.fit(X_train, y_train)
> ```
> 
> gebruikt de estimator de _training data_ om de parameters van het logistic regression model te leren en op te slaan.
> 
> Daarna kan de getrainde estimator deze geleerde parameters gebruiken om bijvoorbeeld predictions te maken:
> 
> ```python
> estimator.predict(X_test)
> ```
