# Scatterplot matrix

> [!info] Scatterplot matrix
> Een **scatterplot matrix** is een matrix van plots waarmee de onderlinge relaties tussen meerdere [[2. Feature, label en target#Feature|features]] tegelijkertijd kunnen worden onderzocht.
>
> Voor iedere combinatie van twee features wordt een *scatterplot* gemaakt. Op de diagonaal wordt meestal de verdeling van iedere afzonderlijke feature weergegeven, bijvoorbeeld met een histogram of KDE.
>
> Een scatterplot matrix is vooral bruikbaar tijdens *exploratory data analysis* om:
> - relaties tussen features te herkennen;
> - mogelijke *correlation* visueel te onderzoeken;
> - clusters of scheiding tussen classes te herkennen;
> - outliers te ontdekken;
> - de verdeling van individuele features te bekijken.
>
> Een scatterplot matrix is een visueel hulpmiddel en vervangt geen statistische maat zoals de [[2. Correlatiecoëfficiënt#Pearson-correlatiecoëfficiënt|Pearson-correlatiecoëfficiënt]]. Een scatterplot kan bijvoorbeeld ook niet-lineaire patronen zichtbaar maken die niet goed door Pearson correlation worden weergegeven.

Bij $p$ geselecteerde features ontstaat een matrix van $p \times p$ plots. Bij veel features wordt een scatterplot matrix daardoor snel groot en onoverzichtelijk.

## Voorbeelddata

In onderstaande voorbeelden bevat `df` meerdere features en een `target`.

```python
features = [
    "sepal length (cm)",
    "sepal width (cm)",
    "petal length (cm)",
    "petal width (cm)",
]
```

Dezelfde features kunnen onder andere met pandas en Seaborn worden gevisualiseerd.

## pandas: `scatter_matrix()`

`pandas.plotting.scatter_matrix()` maakt voor ieder paar numerieke kolommen een scatterplot. Op de diagonaal wordt standaard een histogram weergegeven.

> [!example]+ Voorbeeld
> ```python
> import matplotlib.pyplot as plt
> from pandas.plotting import scatter_matrix
>
> scatter_matrix(
>     df[features],
>     c=df["target"],
>     figsize=(12, 12),
>     marker="o",
>     hist_kwds={"bins": 20},
>     s=60,
>     alpha=0.8,
>     cmap="viridis"
> )
>
> plt.show()
> ```

### Uitleg

`df[features]` bepaalt welke features in de matrix worden opgenomen.

`c` bepaalt de kleur van ieder datapunt. Bij een classification-probleem kan hiervoor de [[2. Feature, label en target#Target|target]] worden gebruikt:

```python
c=df["target"]
```

Observations uit verschillende classes krijgen daardoor verschillende kleuren.

`marker` bepaalt de vorm van ieder datapunt:

```python
marker="o"
```

`hist_kwds` bevat extra argumenten voor de histogrammen op de diagonaal:

```python
hist_kwds={"bins": 20}
```

Hiermee wordt ieder histogram verdeeld in 20 intervallen.

`s` bepaalt de oppervlakte van de markers:

```python
s=60
```

`alpha` bepaalt de transparantie:

```python
alpha=0.8
```

Een lagere waarde maakt overlappende observations beter zichtbaar.

`cmap` bepaalt de gebruikte colormap:

```python
cmap="viridis"
```

### Alternatieve syntax

De functie kan ook via `pd.plotting` worden aangeroepen:

```python
pd.plotting.scatter_matrix(
    df[features],
    c=df["target"]
)
```

Dit is functioneel vergelijkbaar met:

```python
from pandas.plotting import scatter_matrix

scatter_matrix(
    df[features],
    c=df["target"]
)
```

## Seaborn: `pairplot()`

Seaborn biedt met `sns.pairplot()` een vergelijkbare visualisatie.

Een belangrijk verschil is dat `pairplot()` rechtstreeks ondersteuning heeft voor het groeperen op een categorische variabele via `hue`.

> [!example]+ Voorbeeld
> ```python
> import matplotlib.pyplot as plt
> import seaborn as sns
>
> sns.pairplot(
>     data=df,
>     vars=features,
>     hue="target",
>     diag_kind="hist",
>     plot_kws={
>         "s": 60,
>         "alpha": 0.8
>     },
>     diag_kws={
>         "bins": 20
>     }
> )
>
> plt.show()
> ```

### Uitleg

`data` bevat de volledige DataFrame:

```python
data=df
```

Met `vars` wordt bepaald welke features worden weergegeven:

```python
vars=features
```

`hue` bepaalt welke variabele wordt gebruikt om observations met verschillende kleuren weer te geven:

```python
hue="target"
```

Dit vervult ongeveer dezelfde rol als:

```python
c=df["target"]
```

bij `scatter_matrix()`.

`diag_kind` bepaalt het type plot op de diagonaal:

```python
diag_kind="hist"
```

Een andere mogelijkheid is bijvoorbeeld:

```python
diag_kind="kde"
```

`plot_kws` bevat extra keyword arguments voor de scatterplots:

```python
plot_kws={
    "s": 60,
    "alpha": 0.8
}
```

`diag_kws` bevat extra keyword arguments voor de plots op de diagonaal:

```python
diag_kws={
    "bins": 20
}
```

### Alleen de helft van de matrix

De matrix is symmetrisch: de plot van feature A tegen feature B bevat dezelfde informatie als feature B tegen feature A.

Met:

```python
corner=True
```

kan bij Seaborn alleen de onderste helft worden weergegeven:

```python
sns.pairplot(
    data=df,
    vars=features,
    hue="target",
    corner=True
)
```

Dit kan vooral bij grotere aantallen features de visualisatie overzichtelijker maken.

## `scatter_matrix()` versus `pairplot()`

| Eigenschap | pandas `scatter_matrix()` | Seaborn `pairplot()` |
| --- | --- | --- |
| Library | pandas | Seaborn |
| Features selecteren | DataFrame vooraf selecteren | `vars=` |
| Classes kleuren | `c=` | `hue=` |
| Legenda voor classes | Beperkt | Automatisch |
| Diagonaal | Histogram of KDE | Histogram, KDE of geen |
| Extra scatter-instellingen | Directe keyword arguments | `plot_kws` |
| Extra diagonaal-instellingen | `hist_kwds` | `diag_kws` |
| Alleen halve matrix | Niet direct | `corner=True` |
| Gebruik | Snelle inspectie | Meer high-level functionaliteit |

Beide functies visualiseren in essentie hetzelfde concept: de pairwise relationships tussen meerdere features.

## Interpretatie

Stel dat twee features:

```text
flavanoids
od280/od315_of_diluted_wines
```

duidelijk verschillende clusters laten zien wanneer observations op basis van hun `target` worden gekleurd.

Dit geeft aan dat deze features mogelijk informatie bevatten waarmee de verschillende classes van elkaar kunnen worden onderscheiden.

Een duidelijk lineair patroon tussen twee features kan daarnaast wijzen op een hoge [[2. Correlatiecoëfficiënt#Pearson-correlatiecoëfficiënt|Pearson-correlatiecoëfficiënt]].

> [!info]
> Een sterke relatie tussen twee features betekent niet automatisch dat beide features afzonderlijk veel nieuwe informatie toevoegen. Sterk gecorreleerde features kunnen deels dezelfde informatie bevatten.

## Veel features

Het aantal posities in de matrix neemt kwadratisch toe met het aantal features:

```text
4 features  →  16 posities
10 features → 100 posities
20 features → 400 posities
```

Bij datasets met veel features is het daarom meestal nuttiger eerst een relevante subset van features te selecteren.
